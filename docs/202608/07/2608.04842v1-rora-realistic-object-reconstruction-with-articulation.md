## 摘要
通过如NeRF和3D高斯泼溅（3DGS）等逼真视觉表示将真实世界环境复制到仿真中，已成为减少机器人学习中的仿真到现实差距的有效策略。然而，在现实到仿真过程中实现物体关节化仍然是一项具有挑战性的任务。现有的基于运动跟踪或学习的关节化方法在具有多个关节的复杂运动学结构上成功率较低。此外，这些方法需要扫描物体的动态运动，这使得重建过程变得更加复杂。在这项工作中，我们提出了首个端到端流水线，通过基于建议的人机交互过程，从单个静态物体视频输入中重建具有精确关节的仿真就绪资产。我们的方法导出一个混合表示，结合3DGS用于照片级真实感渲染，以及基于网格的几何用于物理交互。在重建过程中，我们的流水线执行凸分解，随后由用户分组进行直观的部分分割，然后将3D高斯绑定到相应的网格部分。然后，自动关节建议算法从局部边界几何计算候选关节轴，并将其呈现给用户，以实现高效的关节资产重建。我们已经证明，我们的方法在partnet-mobility-v0数据集和真实物体上实现了精确的关节化结果。此外，我们展示了我们的框架在机器人学习中的潜在用途，将重建资产部署在虚幻引擎和NVIDIA Isaac Sim中，演示了实时的灵巧手操作任务。

## Abstract
Replicating real-world environments into simulation by realistic visual representation like NeRF and 3D Gaussian Splatting (3DGS) has emerged as an effective strategy to reduce the sim-to-real gap in robot learning. However, implementing object articulation during the real-to-sim process is still a challenging task. Existing motion tracking or learning based articulation methods shows low success rates on complex kinematic structures having multiple joints. Furthermore, those methods require scan of dynamic motion of objects, which makes reconstruction process much complicated. In this work, we propose the first end-to-end pipeline that reconstructs simulation-ready assets with accurate articulation from a single static object video input through suggestion based human-in-the-loop process. Our approach exports a hybrid representation combining 3DGS for photorealistic rendering and mesh-based geometry for physical interaction. In the reconstruction process, our pipeline performs convex decomposition followed by user grouping for intuitive part segmentation, subsequently binding 3D Gaussians to the corresponding mesh parts. An Automatic Joint Suggestion Algorithm then calculates candidate joint axes from local boundary geometries and presents them to users for efficient articulated asset reconstruction. We have shown that our method achieves precise articulation results on partnet-mobility-v0 dataset and real objects. Additionally we presented a potential usage of our framework on robot learning, deploying the reconstructed assets in Unreal Engine and NVIDIA Isaac Sim, demonstrating real-time dexterous hand manipulation tasks.

## 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

### 核心思想
利用物体可动子部件在几何上的“凸出”特征，通过**凸分解 + 轻量用户分组**实现部件级分割，再根据**局部边界几何**自动推断关节候选轴，由用户在 GUI 中确认与微调，最终导出可仿真资产。整个过程只需静态场景的单次视频扫描，用户交互时间极短。

### 整体流水线（6 个阶段）
1. **初始重建（Initial Reconstruction）**：采用 GS2Mesh 流水线，从单段视频生成 3DGS 和网格。借助 SAM2 生成过滤掩码，通过“可见性计数”筛选出属于目标物体的高斯点。
2. **网格细化（Refinement）**：对初始网格进行修复，生成水密（watertight）表面。步骤包括：PCA 计算底部孔洞平面法线并对齐空间、滤除孤立碎片（Algorithm 1）、Screened Poisson 重建、移除地面以下顶点、二次边折叠减面、各向同性重网格化、底部空洞填充、全局补洞等，确保后续图分析的拓扑完整性。
3. **凸分解（Decomposition）**：采用 Approximate Convex Decomposition（ACD）算法，将网格分解为若干不重叠的凸碎片，覆盖整个物体表面。
4. **部件分割（Segmentation，含人机交互）**：由于自动分割模型在子部件外观相似时容易失败，用户只需为分解出的凸碎片分配组号（1,2,3,...），即可形成语义正确的子部件。网格上未被凸碎片覆盖的顶点按 L2 距离分配到最近组；高斯点通过 k 近邻（KNN）投票绑定到对应的网格子部件，得到网格与 3DGS 的统一部件分割。
5. **关节化（Articulation，含人机交互）**：由 **Automatic Joint Suggestion Algorithm** 自动生成关节候选，用户通过 GUI 确认/选择关节轴、指定关节类型（fixed/revolute/prismatic）并微调位置。算法包含 4 个关键步骤（详见下文）。
6. **导出（Export）**：生成统一的 URDF 文件编码关节运动学，同时将 3DGS 绑定至对应运动链连杆，实现仿真环境中的照片级渲染与物理交互。

### 自动关节建议算法（Automatic Joint Suggestion Algorithm）
该算法是本文方法的核心创新，包含 4 个步骤：

1. **边界检测（Boundary Detection）**：对每个子部件 i，提取其与相邻子部件 j 相邻的边界顶点，构建诱导子图，剪除度数小于 2 的顶点；通过深度优先搜索（DFS）枚举所有简单候选环；按边长度降序贪心选取，保留相对已选环边独有比例超过阈值 τ（默认 0.5）的环，得到边界环集合 Cᵢ。
2. **轴估计（Axis Estimation）**：对每个边界环构造“单向连接”（unidirectional connection）uₐ = (oₐ, nₐ, xₐ），其中：
   - oₐ：环顶点的质心（关节原点）；
   - nₐ：法线向量，通过**单平面估计**获得——在局部邻域内拟合线性 SVM，取分离超平面的归一化法向量；
   - xₐ：交线向量，通过**多平面估计**获得——对非平面/角型边界，使用 EM 框架协调 K=2 个超平面，区分凸/凹角两种赋值策略，选择分类精度更高的构型，取两个超平面交线方向作为 xₐ。
3. **双向融合（Bidirectional Fusion）**：同一物理界面在子部件 i 和 j 两侧可能产生不一致的单向连接。取 U_{i→j} 与 U_{j→i} 配对，求各向量均值，得到双向连接 B = (o, n, x, p)，其中 p = n × x 为叉积向量；n、x、p 三个向量共同作为候选关节轴。
4. **关节建议（Joint Suggestion）**：针对同一子部件对之间存在多个物理界面的复杂拓扑（如工具箱把手两端连接箱体），引入几何启发式：
   - **两个连接**：在两连接原点中点处新增候选轴，方向沿两原点连线（图 4 示例）；
   - **三个及以上连接**：关节原点取所有连接原点的算术平均，轴沿平均法向量方向。

### 对比方法
- **Articulate-Anything (AA)**：基于 VLM 的自动化关节建模基线；
- **ScrewSplat**：基于螺旋理论、扩展 3DGS、从多状态 RGB 观测联合优化螺旋轴基元的端到端方法。

### 评估指标
- **几何指标（Geometry Metrics）**：评价关节估计精度与真值（GT）的偏差，包括：
  1. 类型误差（Type error）：误分类或遗漏的关节数；
  2. 角度误差（Angular error）：估计轴与 GT 轴的角度偏差（范围 [0°, 90°]）；
  3. 位置误差（Positional error）：旋转关节预测原点与 GT 原点在正交方向上的 ℓ2 距离。
- **视觉指标（Visual Metrics）**：将资产驱动至测试构型后与 GT 渲染图比较，使用 PSNR、SSIM、LPIPS。
- **运行时间（Runtime）**：对比各流水线的端到端耗时。

### 真实世界与仿真部署实验

## 6. 论文的主要结论与发现

- 在 PartNet-Mobility 基准上，**RORA 在全部三个难度类别的几何指标（类型/角度/位置误差）和视觉指标（PSNR/SSIM/LPIPS）上均优于 Articulate-Anything 和 ScrewSplat**。
  - 尤其是链式连杆（Category III）中，基线的角度误差高达 22.5°–62.8°，而 RORA 仅为 0.849°，位置误差也远小于基线（0.028m vs. 0.636–1.367m）。
  - 多关节（Category II）场景下基线已出现 1–2 个关节的类型误差和高达 39.95° 的角度误差，而 RORA 的类型误差仅 0.167、角度误差 1.425°。
- 基线的失败集中在多关节和链式结构上：AA 常检索到不匹配的网格模型，ScrewSplat 则无法为每个关节单独分离运动学，或过度计数关节。
- RORA 凭借**几何驱动的关节建议 + 轻量用户确认**，在近乎自动化（交互 42 秒）的前提下实现了高精度关节重建，且总耗时与全自动基线相当（约 7 分钟）。
- 真实世界的定性实验表明，RORA 能重建出保留精细视觉细节（文字、纹理）且运动学准确的真实物体资产，而基线在分布外真实物体上失败。
- 仿真部署证明：重建资产可直接导入 Unreal Engine 和 NVIDIA Isaac Sim，支持实时灵巧手遥操作和人形双臂操作，展示了其在机器人数据采集和策略学习中的应用潜力。

## 8. 不足与局限

1. **几何特征依赖**：部件分割和关节建议依赖几何“凸出”特征，对**非凸出可动部件**或**相对整体尺度极小的子部件**容易失效。
2. **初始重建的材质局限**：继承了 3DGS 的固有缺陷，对**反射面、透明/玻璃表面**的重建效果差，影响后续分割与关节估计。
3. **实验规模有限**：定量基准仅 16 个对象，缺少大规模统计验证；未开展消融实验（如去掉用户反馈、不同分解算法、不同边界提取参数的影响），难以量化各模块的独立贡献。
4. **缺少误差不确定性分析**：未报告多次运行的标准差/误差条，无法评估方法的稳定性与可重复性。
5. **关节类型覆盖**：几何指标的位置误差仅评估了旋转关节，棱柱关节（prismatic）的精度未做定量验证。
6. **公平性考量**：与基线相比，RORA 多了一次额外的用户反馈信息，而基线为全自动方法；虽然交互时间很短，但严格来说并非完全同等条件下的对比。另外，真实世界实验仅有定性展示，没有定量指标。
7. **用户依赖**：虽然交互较简，但若用户分组质量不高或对候选关节判断失误，仍可能影响最终关节精度；方法并非完全自动化。
8. **应用边界**：当前方法面向单一物体的重建，尚不涉及多物体场景或物体间交互关节（如铰链门、抽屉等多部件联动结构的更大规模场景）的建模。
