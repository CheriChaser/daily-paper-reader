## 摘要
前馈3D高斯泼溅（3DGS）能够实现高效且泛化的3D重建，但当前用于场景理解的前馈3DGS方法大多以类别为导向。相比之下，实例感知的3DGS方法通常依赖逐场景优化，且往往将重建与实例和语义学习解耦，限制了它们之间的相互促进作用。我们提出了InstanceSplat，一个统一的前馈3DGS框架，用于从无位姿多视图图像中进行泛化的3D重建和实例感知场景理解。在单次前向传播中，InstanceSplat构建了一种实例感知的高斯表示，联合编码外观、几何、实例身份和与语言对齐的语义。共享的3D高斯在视图间锚定实例身份，产生可渲染且跨视图一致的实例特征。为了使重建和场景理解相互受益，我们进一步设计了一种以实例为中心的学习策略，通过共享实例结构将重建、实例学习和语义学习连接起来。具体而言，实例线索引导重建，与语言对齐的语义增强了对易混淆同类别实例的区分，实例区域将语义证据聚合为连贯的物体级预测。在不同输入视图设置和未见数据集上的新视角合成、实例分割和开放词汇语义理解实验表明，我们的方法达到了最先进的性能、实用效率和强泛化能力。

## Abstract
Feed-forward 3D Gaussian Splatting (3DGS) enables efficient and generalizable 3D reconstruction, but current feed-forward 3DGS methods for scene understanding remain largely category-oriented. In contrast, instance-aware 3DGS methods typically rely on per-scene optimization and often decouple reconstruction from instance and semantic learning, limiting reciprocal interactions among them. We present InstanceSplat, a unified feed-forward 3DGS framework for generalizable 3D reconstruction and instance-aware scene understanding from pose-free multi-view images. In a single forward pass, InstanceSplat constructs an instance-aware Gaussian representation that jointly encodes appearance, geometry, instance identity, and language-aligned semantics. Shared 3D Gaussians ground instance identities across views, producing renderable and cross-view-consistent instance features. To allow reconstruction and scene understanding to benefit from each other, we further design an instance-centric learning strategy that connects reconstruction, instance learning, and semantic learning through shared instance structure. Specifically, instance cues guide reconstruction, language-aligned semantics strengthen the discrimination of confusing same-category instances, and instance regions aggregate semantic evidence into coherent object-level predictions. Experiments on novel-view synthesis, instance segmentation, and open-vocabulary semantic understanding under varying input-view settings and on an unseen dataset demonstrate state-of-the-art performance, practical efficiency, and strong generalization.

### 1. 核心问题与整体含义（研究动机与背景）

- **背景**：3D高斯泼溅（3DGS）因其高质量的新视图合成（NVS）和高效渲染能力，在3D场景理解中备受关注。然而标准3DGS仅面向视觉重建，不显式编码实例结构或语义信息。
- **现有方法的两大范式及其局限**：
  - **场景特定方法（Scene-specific）**：如 Gaussian Grouping、OpenGaussian、InstanceGaussian 等，在逐场景优化后的3DGS上附加实例/语义特征。问题在于：依赖逐场景优化，效率低；且通常将重建、实例学习、语义分配分为独立阶段，无法实现三者间的相互促进。
  - **前馈方法（Feed-forward）**：如 LSM、Uni3R、C3G 等，可直接重建未见场景，但表示大多是类别导向的，难以区分实例、保持清晰的物体边界，缺乏显式实例建模。
- **核心问题**：是否存在一个统一的前馈框架，能够从无位姿多视图图像中同时实现高效泛化的3D重建与实例感知的场景理解，并且让重建和理解为彼此提供增益？
- **论文答案**：InstanceSplat 在单次前向传播中构建“实例感知高斯表示”，联合编码外观、几何、实例身份和语言对齐的语义，实现重建、实例学习与语义学习的双向促进。

### 2. 方法论（核心思想、关键技术细节）

#### 2.1 核心思想
- 将实例身份作为3D高斯的固有属性（而非重建后的附加特征），以共享3D高斯为“载体”跨视图锚定实例身份，从而实现可渲染、跨视图一致的实例特征。
- 以实例结构作为重建与语义理解之间的**共享接口**，通过 “Instance-Centric Coupling” 建立三者的双向交互。

#### 2.2 技术框架与关键模块

- **Instance-Aware Gaussian Representation（实例感知高斯表示）**
  - 输入 N 张无位姿图像，前馈网络预测相机参数、深度图、点图、稠密高斯集。
  - 基于 VGGT 的 DINOv2 骨干 + 24层 Transformer（交替帧内/帧间注意力）编码多视图；DPT 风格解码器预测几何与高斯属性；实例解码器预测 8 维像素对齐实例特征。
  - 每个高斯包含：位置 μ、旋转 R、尺度 s、颜色 c、不透明度 α、置信度 C、实例嵌入 S（8维）、语义特征 L。
  - 使用 **置信度感知体素化（confidence-aware voxelization）** 合并冗余高斯，融合实例与语义特征，得到紧凑的体素对齐高斯集 G′。

- **3D-Consistent Instance Grounding（3D一致实例接地）**
  - 通过 **可微渲染**（与RGB渲染相同的 alpha 合成）将实例嵌入渲染到监督视图：
    - \(\tilde{S}_i = \mathcal{R}_{ins}(G', t_i)\)
  - 在渲染空间进行 **原型对比学习**，包含三个损失项：
    - **L_pull**：视图内像素特征拉向其实例原型（类内紧凑）
    - **L_push**：视图内不同实例原型相互推开（类间分离）
    - **L_cross**：跨视图同一实例原型对齐（跨视图一致）
  - 总损失：\(\mathcal{L}_{ins} = \lambda_{pull} L_{pull} + \lambda_{push} L_{push} + \lambda_{cross} L_{cross}\)
  - 由于不同视图通过同一组3D高斯耦合，实例特征天然具备跨视图一致性与可渲染性。

- **Instance-Centric Coupling（实例中心耦合）**
  - **Boundary-Aware Reconstruction（边界感知重建）**：从实例特征图计算像素间的最大余弦距离，得到边界分数，经局部窗口扩展和 sigmoid 映射为软边界权重 b(p)，用于加权 RGB 重建损失 \(\mathcal{L}_{bd-rgb}\)，聚焦物体边界区域的几何优化。
  - **Semantic-Guided Instance Discrimination（语义引导的实例判别）**：渲染语义特征并投影到语言对齐的教师空间（LSeg），利用语义相似度动态加权难负样本对：语义相近（同类别）的实例对获得更大 push 权重 η，从而增强对易混淆同类别实例的区分。
  - **Instance-Grounded Semantic Aggregation（实例接地语义聚合）**：推理时对渲染的实例特征做 HDBSCAN 聚类得到实例区域，在实例区域内聚合语义特征，得到物体级语义原型，再与文本嵌入匹配，抑制逐像素语义噪声，实现边界清晰的物体级开放词汇语义预测。

- **总体训练目标**：\(\mathcal{L} = \mathcal{L}_{rgb} + \mathcal{L}_{distill} + \lambda_{ins}\mathcal{L}_{ins} + \lambda_{sem}\mathcal{L}_{sem} + \lambda_{bd}\mathcal{L}_{bd-rgb}\)

### 6. 主要结论与发现

- InstanceSplat 构建了统一的、从无位姿多视图图像到实例感知3DGS的端到端前馈框架，实现新视图合成、实例分割、开放词汇语义理解的联合支持。
- 共享3D高斯作为实例身份的跨视图锚定载体，显著提升了实例的跨视图一致性和时序稳定性（T-mIoU/T-SR 均优于 IGGT）。
- 实例结构与语义/重建之间能够形成有效的双向促进：实例边界信息改善重建几何、语义相似性提升同类别实例的判别力、实例区域提高语义预测的物体级一致性。
- 相比逐场景优化方法（分钟级），InstanceSplat 在秒级内完成重建+理解，且在未见数据集上具有强泛化能力。

### 7. 优点

- **统一性与简洁性**：一个前馈框架、一次正向传播即可得到同时用于重建、分割、语义理解的表示，避免多阶段复杂流水线。
- **创新的实例中心耦合设计**：以实例结构为共享接口，实现重建↔实例↔语义三者互促，概念清晰、技术实现巧妙（边界感知加权、语义引导难负样本、实例接地聚合）。
- **计算效率突出**：推理时间相比逐场景优化方法快 2~3 个数量级（秒级 vs 分钟级）。
- **跨视图一致性强**：通过共享高斯耦合不同视图，而非在2D特征空间对比学习，从机制上保证3D一致性。
- **泛化能力好**：在训练时为见过的 LERF 数据集上仍能取得 SOTA，显示较强的跨域泛化。

### 8. 不足与局限

- **聚类开销随规模增长**：作者自己指出，推理时 HDBSCAN 特征聚类的成本会随视图数和高斯数增加而显著上升，限制了向大规模场景扩展的能力。
- **mAcc 的稳定性问题**：在 4-view 设置下 mAcc 低于部分基线，作者归因于类别不均衡，但这也说明该方法在小视图设置下对类别分布的鲁棒性有待加强。
- **跨数据集性能波动**：在 LERF 上从 8 视图增加到 16 视图时性能反而下降，作者认为域偏移导致位姿精度下降、跨视图错位累积。这提示方法对位姿估计精度较敏感。
- **对比公平性的潜在局限**：部分对比方法（如 LSeg、AnySplat）未报告全部指标，且不同方法的训练数据/协议存在差异，读者需谨慎对比绝对值。
- **依赖预训练教师模型**：语义学习依赖 LSeg 教师特征，其上限受教师模型语言-视觉对齐能力约束；实例监督依赖高质量 GT 实例掩码，在无 GT 掩码的场景中需要额外获取。
