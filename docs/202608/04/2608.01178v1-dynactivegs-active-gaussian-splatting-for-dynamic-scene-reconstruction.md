## 摘要
我们提出了DynActiveGS，一种基于3D高斯溅射(3DGS)的动态感知主动重建框架，用于动态环境中的自主探索。该框架通过在线不确定性预测和不确定性加权高斯优化，增量式地重建3D高斯场景表示，同时抑制运动污染观测。DynActiveGS的一个关键组成部分是将不确定性显式分解为结构不确定性和运动引起的不确定性，这使系统能够区分重建不足的静态区域和动态不可靠区域。基于这些不确定性场，DynActiveGS执行动态感知的视点选择和动态约束的路径规划，以在探索过程中偏好信息丰富且稳定的观测。由此产生的系统形成了一个统一的闭环管线，用于动态场景中稳健的主动重建。在具有挑战性的动态基准上的大量实验表明，在重建精度、完整性、渲染质量和探索效率方面，与现有主动重建基线相比有一致的改进。

## Abstract
We present DynActiveGS, a dynamic-aware active reconstruction framework based on 3D Gaussian Splatting (3DGS) for autonomous exploration in dynamic environments. The framework incrementally reconstructs a 3D Gaussian scene representation while suppressing motion-corrupted observations through online uncertainty prediction and uncertainty-weighted Gaussian optimization. A key component of DynActiveGS is the explicit decomposition of uncertainty into structural uncertainty and motion-induced uncertainty, which enables the system to distinguish under-reconstructed static regions from dynamically unreliable areas. Based on these uncertainty fields, DynActiveGS performs dynamic-aware viewpoint selection and dynamic-constrained path planning to favor informative yet stable observations during exploration. The resulting system forms a unified closed-loop pipeline for robust active reconstruction in dynamic scenes. Extensive experiments on challenging dynamic benchmarks demonstrate consistent improvements over existing active reconstruction baselines in reconstruction accuracy, completeness, rendering quality, and exploration efficiency.

## 1. 核心问题与研究动机

- **背景**：以 3D 高斯溅射（3DGS）为代表的显式场景表示凭借实时渲染与增量优化能力，已成为主动 3D 重建（active 3D reconstruction）的热门基础。现有主动重建方法（如 ActiveGAMER、ActiveSplat、NARUTO、ActiveGS 等）大多基于静态环境假设，通过“下一最佳视点”（Next-Best-View, NBV）规划来探索未知场景。
- **核心问题**：现实世界中普遍存在的动态对象（行人、车辆、可动机构等）会对主动重建产生三方面根本性破坏：
  1. **运动污染的观测退化高斯优化**——动态物体在图像中留下拖影、重影与重复结构，导致高斯参数被错误更新；
  2. **扭曲不确定性估计**——动态干扰使视点选择所依赖的“信息量”评估失真；
  3. **误导视点规划**——规划器可能被高增益但低可靠性的动态区域吸引。
- **研究空白**：已有动态 3DGS / 高斯 SLAM 工作主要聚焦于被动建图和动态物体过滤，**缺乏主动感知与长时程探索能力**；而主动重建方法又普遍忽视动态干扰。两者交叉的“动态环境中的主动重建”尚未被系统解决。
- **论文目标**：提出 DynActiveGS——一个**动态感知、闭环（感知–规划–重建）的主动 3DGS 重建框架**，将动态干扰显式建模到不确定性估计、高斯优化、视点选择与路径规划的全链路中，使智能体在动态场景中既能高效探索，又能保持静态场景重建的精度与完整性。

## 2. 方法论与技术细节

### 2.1 核心思想

DynActiveGS 的核心是将不确定性**显式分解**为两类地图级场：
- **结构不确定性**（Structural Uncertainty, $U_s$）：反映静态场景“哪里还没被充分重建”；
- **运动不确定性**（Motion-induced Uncertainty, $U_m$）：反映“哪里即使观测了也高度不可靠”。

二者共同驱动视点选择与路径规划，使探索偏向**信息丰富且观测稳定**的区域，同时在优化阶段抑制运动干扰。

### 2.2 动态感知的高斯重建（Dynamic-aware Gaussian Reconstruction）

**① 帧级不确定性预测**
- 对每帧 RGB 图像 $I_t$，使用预训练 DINOv3 编码器提取稠密视觉特征 $F_t = \mathcal{F}(I_t)$；
- 将特征图输入轻量不确定性预测网络 $\mathcal{P}$，输出逐像素不确定性图 $\beta_t = \mathcal{P}(F_t)$；
- $\beta_t(u)$ 反映像素 $u$ 的可靠性——动态运动或瞬态遮挡区域的不确定性值更高。

**② 不确定性加权高斯建图（Uncertainty-weighted Gaussian Mapping）**
- 给定当前高斯地图 $G_t$、相机位姿 $T_t$ 与内参 $K$，渲染预测 RGB 图 $\hat{I}_t$ 与深度图 $\hat{D}_t$；
- 不确定性加权渲染损失：
  $$
  \mathcal{L}_{\text{render}} = \lambda_1 \mathcal{L}_{\text{color}} + \frac{\lambda_2 \mathcal{L}_{\text{depth}}}{\beta_t^2} + \lambda_3 \mathcal{L}_{\text{iso}}
  $$
  其中 $\mathcal{L}_{\text{color}}$ 结合逐像素 L1 与 SSIM，$\mathcal{L}_{\text{iso}}$ 为各向同性高斯正则项。核心是**用不确定性图作为逐像素权重**，使不可靠观测对高斯更新的贡献被大幅削减。

**③ 地图级结构与运动不确定性**
- 结构不确定性（式 8）：

  $$
  U_s(\mathbf{x}) = \lambda_c \frac{1}{\sqrt{n_t(\mathbf{x}) + \epsilon}} + \lambda_r \, \text{clip}(\bar{e}_t(\mathbf{x}), 0, e_{\max})
  $$

  第一项奖励低观测次数区域，第二项惩罚当前高斯地图难以解释的区域；
- 运动不确定性（式 9，指数滑动平均更新）：

  $$
  U_m(\mathbf{x}) \leftarrow (1-\alpha) U_m(\mathbf{x}) + \alpha \, \mathbb{1}_t(\mathbf{x}) \, \beta_t(u_t)
  $$

  将帧级不确定性投影到 3D 并随时间累积，使**持续动态区域**被稳定标记。

### 2.3 动态感知的视点选择（Dynamic-aware Viewpoint Selection）

- 采用 **Voronoi 图** $G = (V, E)$ 的层次化规划：每个节点表示可达区域，边表示连通性；
- **动态感知子区域划分**（式 10）：使用凝聚聚类，节点间距离综合欧氏距离、图上旅行距离与沿路径累积运动风险：
  $$
  d_{\text{dyn}}(n_i, n_j) = \lambda_e d_E + \lambda_p d_P + \lambda_m d_M
  $$
- **局部–全局双层评分**：
  - 局部评分（式 11）：优先探索当前子区域，在结构增益 $I_s$ 中减去运动风险 $R_m$ 与旅行代价 $C$；
  - 全局评分（式 14）：当局部区域探索充分或变得不稳定时，切换到全局——对各候选子区域计算聚合结构与运动效用，并惩罚旅行距离和已访问区域；
  - `Vis(n, x) ∈ [0,1]` 为当前高斯地图下的软可见性得分，用于计算观测的信息增益与风险。

### 2.4 动态约束的路径规划（Dynamic-constrained Path Planning）

- 每条图边的通行代价（式 15）：
  $$
  c(e) = \ell(e) + \lambda_m \bar{U}_m(e)
  $$
  即几何边长度 + 沿边平均运动风险；
- 路径总代价（式 16）为边代价求和，**避免穿过高风险动态区域的“捷径”**；
- 运动不确定性采用指数滑动平均在时间上平滑（式 17），保证瞬态扰动不主导规划，而持续性动态区域被稳定规避。

### 2.5 闭环流程

智能体每步获取 RGB-D 观测 → 更新高斯地图与两类不确定性场 → 在 Voronoi 图上选择信息丰富且稳定的目标视点 → 规划动态安全轨迹并执行 → 循环直至步数预算 $S$ 耗尽。

## 6. 主要结论与发现

1. **动态扰动的本质影响**：现有静态主动重建方法的瓶颈并非“视点采样能力不足”，而是**缺乏运动感知的决策能力**——无法区分高增益但高风险的观测；
2. **指标上的全面领先**：
   - Social-MP3D：平均 Acc 从最强基线 ActiveGAMER 的 4.34cm 降至 **2.86cm**，C.R. 从 90.17% 提升至 **94.08%**，PSNR 从 21.48 提升至 **23.04**，LPIPS 从 0.410 降至 **0.279**；
   - Dynamic Gibson：平均 Acc 从 3.98cm 降至 **2.52cm**，C.R. 从 91.40% 提升至 **94.82%**，PSNR 从 22.24 提升至 **24.34**，LPIPS 从 0.397 降至 **0.288**；
3. **每个组件均有贡献**：不确定性加权建图、运动感知视点选择、动态约束规划逐项带来稳定增益，且三者叠加效果最优；
4. **探索效率显著提升**：在探索全程中，DynActiveGS 的 PSNR 与完成率提升速度均快于所有基线（图 5）；
5. **有效性不依赖特定数据集**：即使动态行人通过外部协议注入而非原生嵌入，框架依然保持稳定性能，说明运动不确定性建模具有良好泛化性。

## 7. 方法的优点与亮点

- **首次将动态感知闭环化**：将动态处理（而非简单过滤）融入主动重建的完整闭环，填补了“动态 3DGS 被动建图”与“静态主动重建”之间的研究空白；
- **不确定性显式解耦**：将不确定性分解为结构不确定性与运动不确定性，是区分“该看哪里”与“哪里看了也白看”的关键创新，简洁且具有可解释性；
- **端到端一致的“分级防御”**：在**优化层**（不确定性加权损失抑制脏观测）、**规划层**（运动风险从视点评分中扣除）与**执行层**（动态约束路径规划避开高风险走廊）三级联动防御动态干扰；
- **实用化的具身设定**：采用地面移动机器人而非自由飞行相机，更贴近真实机器人部署场景；
- **完备的消融体系**：从模块级、视点选择级、规划器级、长时程效率四个层面验证设计，证据链清晰；
- **开放可复现的基准**：构建了可复现的 Dynamic Gibson Protocol，为后续研究在动态场景中做主动重建提供了统一的评测手段。

## 8. 不足与局限

- **仿真评估单一**：所有实验均在 Habitat 仿真中进行，虚拟行人的运动模式与真实人群（更复杂、更不可预测、更细微的非刚体运动）存在差距，真实机器人部署验证缺失；
- **未披露算力资源**：论文未报告 GPU 型号/数量、训练与推理耗时，复现和工程成本无法预估；
- **环境规模受限**：方法未针对大规模、多楼层复杂空间结构进行优化和评估，分层规划的泛化性未知；
- **动态对象类型单一**：仅覆盖行走的行人，未涉及车辆、动物、机械臂等不同运动学特征的目标；评估指标也明确排除了动态对象的重建，等于“绕行式规避”而非“建模式重建”动态内容；

- **统计稳健性存疑**：结果未报告多次随机运行的标准差，也未做显著性检验，仅有单次（或固定种子）数值，可能掩盖方法在某些场景上的随机波动。
