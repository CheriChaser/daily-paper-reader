## 摘要
端到端（E2E）自动驾驶算法需要在提供高视觉保真度、强交互性和实时性能的仿真环境中进行严格的闭环验证。现有方法（从游戏引擎到静态神经渲染）本质上在这些需求之间进行权衡，并难以应对E2E测试所必需的动态场景合成。为弥合这一差距，我们提出了一种专门针对大规模E2E评估的新型解耦3D高斯泼溅（3DGS）框架。我们使用以对象为中心的规范表示，从根本上将场景分解为高保真静态背景和可操作的动态代理。为解决由此产生的表示冲突，我们引入了三个针对性模块：（1）通过感知剪枝和向量量化的资产压缩，用于实时交通渲染；（2）利用语义拓扑的映射引导几何配准，以严格对齐轨迹；（3）基于代理的重光照，传递环境光照以实现无缝的光度集成。大量实验表明，DecoupleGS实现了保真度与效率的平衡权衡，提高了度量与光度一致性，并为E2E自动驾驶评估提供了一个实用的闭环传感器仿真平台。

## Abstract
End-to-end (E2E) autonomous driving algorithms require rigorous closed-loop validation in simulation environments offering high visual fidelity, strong interactivity, and real-time performance. Existing approaches, from game engines to static neural rendering, inherently trade off these requirements and struggle with the dynamic scene composition essential for E2E testing. To bridge this gap, we propose a novel decoupled 3D Gaussian Splatting (3DGS) framework tailored for large-scale E2E evaluation. We fundamentally decompose scenes into a high-fidelity static background and manipulable dynamic agents using an object-centric canonical representation. To resolve resulting representational conflicts, we introduce three targeted modules: (1) asset compression via perceptual pruning and vector quantization for real-time traffic rendering; (2) map-guided geometric registration leveraging semantic topology to strictly align trajectories; and (3) proxy-based relighting transferring ambient illumination for seamless photometric integration. Extensive experiments demonstrate that DecoupleGS achieves a balanced fidelity-efficiency trade-off, improves metric and photometric consistency, and provides a practical closed-loop sensor simulation platform for E2E autonomous driving evaluation.

## 2. 方法论

### 2.1 整体架构

DecoupleGS采用**双流架构**：静态背景与动态代理分别在不同坐标空间中表示，在光栅化之前数学融合，无需网络推理。整个流程包括三个核心模块（资产压缩、地图引导几何配准、基于代理的重光照），最终通过统一光栅化器合成多视角图像。

### 2.2 目标中心规范分解与统一渲染

- 全局场景 Ω(t) 定义为时不变背景场 **Sbg** 与 K 个动态代理的并集：

  Ω(t) = Sbg ∪ (∪_{k=1..K} T_k(t) ∘ V_k)

- 每个动态代理 k 在标准局部坐标系（LCS）中参数化为规范高斯体积 V_k，通过6自由度刚体变换 T_k(t) = [R_k | t_k] ∈ SE(3) 映射到世界坐标系，对均值 μ 和协方差 Σ 做变换。
- 针对球谐函数（SH）系数的**视角依赖**特性，使用 Wigner D矩阵 D(R_k) 对SH带进行重定向，保证几何旋转后高光反射方向正确。
- **统一光栅化**：将背景与动态代理所有图元合并为统一列表，深度排序后进行前向α混合；通过保守视锥剔除、静态背景排序缓存复用、仅对移动体积做批量空间更新等硬件级优化维持实时帧率。

### 2.3 资产压缩模块

- **显式重要性评分与剪枝**：对每个图元计算标量重要性分数：

  s_i = w_vis·V_i + w_col·D_i + w_ent·H_i

  其中 V_i 为可见性（训练视角下期望不透明度贡献）、D_i 为颜色对比度（与局部背景的感知区分度）、H_i 为纹理熵（邻域复杂度）。分数低于阈值 τ_s（经验设为0.005）的图元被剪枝，有效保留轮毂、底盘边界等关键结构。
  
- **属性向量量化（VQ）**：将协方差 Σ_i 和颜色系数 c_i 离散化为最近的码本条目：

  Σ_i ≈ C_shape[q_shape_i]，c_i ≈ C_color[q_color_i]

  码本大小 K_color = 1024（SH颜色）、K_shape = 512（协方差），通过指数移动平均（EMA）优化，初始化使用K-Means而非随机采样。

### 2.4 地图引导几何配准

- **语义拓扑与平面对齐**：从HD地图获取向量化车道中心线（无地图时用MapTRv2提取）；构建同时惩罚欧氏距离和航向偏差的代价矩阵，用有约束的**动态时间规整（DTW）**建立轨迹-车道对应关系，再通过**正交Procrustes分析**求解 SE(2) 最优二维刚体变换以消除系统侧向漂移。
- **垂直接地**：3DGS无连续表面网格，采用**不透明度加权深度累积**对车辆底面锚点求垂直高度：

  z_j = (Σ_{k∈N} α_k z_k) / (Σ_{k∈N} α_k)

  在锚点集合上最小二乘拟合局部地面平面，由平面法线推导最终垂直位置及俯仰/侧倾姿态，保证车轮与地面物理接触。

### 2.5 基于代理的重光照模块

- **局部探针采样与线性SH传递**：将背景SH系数视为密集光照探针场，对位置 x 处的车辆聚合邻域背景高斯的SH系数（按可见性和空间距离加权）得到局部环境描述子 L(x)：

  L(x) = Σ w_g c_g / Σ w_g，w_g = exp(−||x − μ_g||² / 2σ²_p)·V_g

  通过离线最小二乘回归校准的线性算子 T(·) 和 b(·) 对规范SH系数做调制：c_out = T(L(x)) ⊗ c_can + b(L(x))。该算子离线推导，在线运行仅需每帧两次矩阵-向量乘法，完全避免逐帧MLP推理。
- **基于代理的接触阴影**：在估计的局部地面平面上投影参数化超椭圆阴影掩码，强度由环境描述子DC分量的主导光强 I_dom 动态调节，使得晴天阴影强烈、阴天或夜间阴影微弱。

### 2.6 算法流程

- **离线阶段**（Algorithm 1）：原始车辆3DGS → 重要性评分 → 自适应剪枝 → EMA向量量化 → 紧凑规范体积。
- **在线阶段**（Algorithm 2）：地图引导配准（DTW + Procrustes + 不透明度接地）→ 代理重光照（局部环境取样 + SH调制 + 阴影生成）→ 统一光栅化（空间变换 → 聚合 → 深度排序 → α混合）。

## 6. 主要结论与发现

- **DecoupleGS在保真度与效率之间实现了最优平衡**：在三种交通密度下，DecoupleGS是唯一在所有保真度和效率指标上均保持前二的方法（表1最终列）。
- **可扩展性显著优于Vanilla 3DGS**：在多达50个动态代理的极端场景下，Vanilla 3DGS内存爆炸出现OOM，而DecoupleGS保持近似线性内存增长并维持可用帧率。
- **几何配准有效修正轨迹漂移和地面穿透**：结合DTW序列对齐、SE(2)平面校正和不透明度累积垂直接地，实现了精确的车道级放置和物理合理的道路接触。
- **代理重光照实现无缝光度集成**：无需在线网络推理，转移局部环境光照和接触阴影后，插入车辆的前景外观与背景光照的一致性大幅提升（PAE从48.5°降至6.8°）。
- **开环sim-to-real一致性最高**：UniAD在DecoupleGS渲染下的mADE（0.82m）和minTTC（3.3s）最接近真实输入（0.76m / 3.5s），行为差距小于HUGSIM、RealEngine和OASim。
- **闭环测试中综合表现最佳**：驾驶得分0.884、路线完成率0.956、minTTC 3.3s均为最高，且45 FPS的渲染速度大幅超过HUGSIM（12 FPS）和OASim（18 FPS）。
- **不同E2E策略的脆弱性暴露**：UniAD在Easy场景保持较高完成率但受严重遮挡和密集交互影响；VAD对密集多智能体约束更敏感，在Hard/Extreme难度下驾驶得分下降更剧烈——验证了DecoupleGS能生成暴露规划器弱点的结构化压力测试场景。
- **模块具备即插即用能力**：将压缩/配准/重光照模块集成到现有模拟器可同时改善渲染速度和光度一致性。

## 7. 优点

- **问题定义清晰、针对性强**：将自动驾驶神经仿真中的核心困境明确归结为三种可量化的表示冲突（效率、几何、光度），并逐一设计对应模块，"三个冲突→三个模块"的结构高度自洽。
- **真正的闭环交互仿真**：与大多数"半开环"或预渲染方法不同，DecoupleGS实现了完全交互式的闭环系统——E2E策略预测轨迹、IDM+MOBIL背景代理实时反应、全局状态同步后重新渲染，每一步都是真实反馈循环。
- **解耦表示兼具保真与可操控性**：用目标中心规范表示分离背景和前景，既保留了3DGS的高视觉保真，又使车辆可独立编辑

- **统一光栅化设计精妙**：将背景与动态图元合并为单一深度排序列表，配合保守视锥剔除和缓存复用，避免了两遍渲染带来的合成伪影，同时维持实时帧率——这是工程实现上的重要贡献。
- **光照传递机制高效且可微分**：将局部环境光照编码为SH系数场，通过离线回归的线性算子调制规范SH系数，既避免了逐帧神经推理的算力开销，又保持了对环境变化的连续响应，是效率与物理合理性之间的巧妙折中。

## 8. 缺点与局限性

- **地图依赖性强**：几何配准模块强依赖HD地图提供的车道中心线，虽然论文提到了无地图时的MapTRv2替代方案，但该替代方案本身的精度和鲁棒性未在实验中单独验证。在无地图且车道线模糊的非结构道路场景下，配准质量难以保证。
- **光照传递算子线性假设的局限性**：重光照模块假设环境光照到车辆外观的映射可以用线性算子逼近，这在漫反射主导的场景下成立，但对于强镜面反射、多跳间接光照或雨雪天气等复杂光照条件，线性近似的误差会显著增大。
- **动态资产来源与场景不完全匹配**：车辆资产来自3DRealCar数据集，与nuScenes/PandaSet真实场景中的车辆在传感器特性、纹理分辨率、建模精度上存在系统性差异，这种跨数据集组合可能掩盖了方法对真实车辆资产的适配能力（即"干净资产假设"）。
- **行为模型过于简化**：背景代理仅使用IDM+MOBIL模型，缺乏对行人、自行车、交通信号灯、路口让行规则等复杂交通要素的建模，限制了在城市场景中对E2E策略压力测试的全面性。极端场景的构建主要依赖密度和光照变化，而非语义多样化。
- **缺乏大规模真实闭环验证**：闭环测试仅在一个仿真环境中进行，未在真实车辆或真实道路部署验证，也未与其他闭环模拟器做用户研究或主观视觉质量评估。仿真器的最终目的是辅助真实部署，缺少这一环使得结论的外推性受限。
- **消融实验场景覆盖不全**：所有消融实验仅在medium密度场景下执行，未报告Hard/Extreme难度下各模块的独立贡献，因此无法判断重光照模块在对抗性光照下、配准模块在高密度交通流中的实际增益是否与中等场景一致。
- **对极端光照的鲁棒性未充分验证**：虽然场景难度分级中提到了夜间和黄昏，但PSNR等像素级指标在夜间场景中往往受噪声影响而失真，论文未单独给出夜间场景的感知指标或后续规划性能分解，难以确定夜间表现的真正瓶颈。

## 9. 总体评价与研究启示

- **总体定位**：DecoupleGS是一篇工程完成度极高、实验设计严谨的仿真系统论文。它的核心贡献并非某个颠覆性算法，而是将已有的3DGS、向量量化、DTW配准、SH重光照等技术进行系统化整合，在"可交互E2E测试仿真"这一具体问题上给出了一个完整、实用、可复现的解决方案。
- **方法论借鉴意义**：论文展示了一种值得学习的"冲突驱动设计"研究范式——先识别本质矛盾（效率/几何/光度），再为每个矛盾设计最小充分解耦方案，而非从单一算法角度出发强行适配场景。这种从问题到方案的自顶向下结构使得模块边界清晰、消融验证自然。
- **对后续研究的启发**：
  - 动态资产如何实现与背景的**物理级**交互（如形变、损坏、脏污）仍是开放问题；
  - 光照传递从线性算子向轻量级神经场扩展，以覆盖镜面和非朗伯表面的路径值得探索；
  - 背景代理行为模型与基础世界模型的融合，可能是实现真正"智能交通流"的下一步；
  - 将DecoupleGS的训练数据扩展至大规模多城市数据集，并引入自动驾驶大模型作为候选策略，是验证系统通用性的可行方向。
- **阅读建议**：对于从事E2E自动驾驶测试的研究者，本文的仿真架构和实验设计（特别是难度分级体系和开环-闭环双评估协议）具有直接的参考价值；对于从事神经渲染的读者，第2.3节的资产压缩和第2.5节的重光照模块中关于"离线校准+在线线性运算"的工程思想值得借鉴。

综上所述，DecoupleGS在**解耦表征**、**可扩展交互**与**实时渲染**三方面为自动驾驶端到端策略测试提供了一个坚实的高保真仿真基座，虽然在地图依赖、行为丰富度和极端光照验证上仍有提升空间，但其系统架构、评估协议和模块化设计将成为该方向后续研究的重要参照。
