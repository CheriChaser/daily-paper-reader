## 摘要
当前的世界动作模型（WAM）通常操作于2D视觉数据。这些模型可以实现出色的视觉质量，但缺乏对单个对象的显式空间结构，并且重复处理冗余的背景内容。虽然点云可以在3D空间中表示世界，但跨视角对齐和累积可能很困难。在本文中，我们利用显式4D高斯泼溅（4DGS）表示，分别对场景的动态对象和静态背景进行建模。对于动态对象，我们使用策略模型预测未来的智能体动作，并使用世界模型预测其观测到的高斯泼溅的变换。静态背景不需要为未来状态重新生成，因为其中大部分已经在过去的帧中被观测到。这形成了一种以对象为中心的世界动作模型，我们称之为4DGS-WAM。它将2D观测提升为持久的4D表示，以便在未来的预测中复用先前观测到的静态内容。未来状态外推可以专注于建模动态对象的演化。在KITTI-MOT上进行了短时预测和过去重建的实验。

## Abstract
Current world action models (WAMs) typically operate on 2D visual data. These models can achieve exceptional visual quality, but they lack explicit spatial structure for individual objects and repeatedly process redundant background content. Although point clouds can represent the world in 3D space, they can be difficult to align and accumulate across viewpoints. In this paper, we leverage an explicit 4D Gaussian Splatting (4DGS) representation that separately models dynamic objects and the static background of a scene. For dynamic objects, we use a policy model to predict future actor actions and a world model to predict transformations of their observed Gaussian splats. The static background need not be regenerated for future states, as much of it has already been observed in past frames. This forms an object-centric world action model, which we name 4DGS-WAM. It lifts 2D observations into a persistent 4D representation so that previously observed static content can be reused during future prediction. Future-state extrapolation can then focus on modeling the evolution of dynamic objects. Experiments on KITTI-MOT evaluate short-horizon prediction and past reconstruction.

  - **缺乏显式空间结构**：2D表示无法为单个对象提供明确的三维几何与空间结构，限制了模型对物理世界的推理能力。
  - **冗余背景处理**：连续帧中包含大量静态背景的重复信息，基于图像的方法必须反复重新生成这些不随动作改变的像素，计算效率低且无必要。
- **现有3D替代方案的不足**：点云可以在3D空间中表示世界，但其稀疏且无结构的特性使得跨视角对齐、时间累积和密集视角合成变得困难，尤其在视角变化和物体运动的情况下。
- **核心思路**：本文提出利用显式4D高斯泼溅（4D Gaussian Splatting, 4DGS）作为世界动作模型的表示基础，将动态场景显式分解为**动态对象**和**静态背景**两大部分。
- **关键洞察**：过去帧中已经观测到的静态背景无需在未来状态中重新生成，因此未来的外推可以聚焦于动态对象的演化，从而实现更高效、更具结构性的世界建模。

### 7. 优点

- **方法创新性**：第一个将显式4DGS表示与对象中心世界动作模型相结合的工作，区别于主流的MLLM或视频扩散WAM范式。
- **静态背景复用**：避免了重复生成不变内容，从机制上提高了计算效率和时空一致性。
- **对象中心分解**：通过VFM（分割、深度、位姿、光流）实现动态-静态解耦，使未来预测聚焦于动态对象的SE(3)演化，具备更好的可解释性。
- **单次前向外推**：策略网络可在单次评估中直接预测目标时域动作（包括h>1），无需自回归逐步预测中间状态。
- **工程实现细致**：策略与世界模型均采用精心设计的架构（因果注意+记忆令牌、等变张量网络、part-level twist混合、外观传输），并给出了完整的训练细节。

### 8. 不足与局限

- **建模能力限制**：
  - 世界模型按对象独立因子化，**无法建模对象间碰撞与交互**，不适合需要接触的机器人操作任务。
  - **无法实例化在t时刻之后新出现的对象**。
  - 4DGS状态**缺乏形状补全**能力，对未被观测到的物体背面等区域无法建模。
- **感知误差传播**：依赖一系列VFMs（分割、深度、光流、位姿），任一环节的感知错误都会向重建状态和预测动态传播。
- **静态银行局限**：只能保留已观测内容，无法合成新暴露的背景区域，因此定量渲染使用了冻结的NeoVerse融合下垫层弥补未覆盖像素，这在一定程度上使得与基线对比不够纯净。
- **实验覆盖不足**：仅评估短时预测（h=1, 3），长时程深入展开（long-horizon rollout）仍是开放问题；没有消融实验；没有在多种数据集（如机器人操作）上验证泛化性。
- **架构非端到端**：感知、策略、世界模型是分别训练/组合的，论文承认统一的端到端模型留待未来工作。
- **通用性存疑**：4DGS只是一种可行的4D表示，论文也承认同样的对象中心WAM可构建在体素网格、网格等其它编码之上。
