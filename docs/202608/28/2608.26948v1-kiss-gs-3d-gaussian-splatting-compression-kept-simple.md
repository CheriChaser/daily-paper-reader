## 摘要
基于3D高斯溅射（3DGS）的场景重建已变得普遍，然而由于未压缩的文件大小可能非常庞大，部署仍然困难。当前的3DGS压缩系统结合了多种减小文件大小的策略，这可能会掩盖收益来源，并限制组件在不同训练流程中的复用。为了使收益更加透明，我们提出了KISS-GS，一种以“保持简单”原则命名的模块化压缩流程，旨在将压缩与训练完全解耦。给定一个使用原始3DGS重建的3DGS场景，我们能够通过结合最先进的剪枝方案，通过压缩实现15.7倍的缩减。然后我们将其编码为一种基于图像的格式，该格式专为简单、普适的解码而设计。借助SOG-XT格式，我们提出了一种自组织高斯的新型扩展，包含两个主要贡献：（i）自组织2D码本和（ii）并行代表赋值平滑（PRAS），后者利用四元数和尺度参数化的对称性生成更易于编码的2D属性网格。这种编码将场景大小减少了6.6倍。我们表明，可选的编码感知微调能进一步减少2.2倍。在标准3DGS基准测试中，我们简单且模块化的方法相对于未压缩的原始3DGS实现了85倍至319倍的总场景大小缩减，为真实场景树立了新的基准，并在率失真方面超越了紧密集成的方法。解码仅依赖于Web原生图像格式，并且模块化设计使每个阶段易于与未来的重建和压缩进展相结合。代码与项目页面：https://fraunhoferhhi.github.io/KISS-GS/

## Abstract
Scene reconstruction with 3D Gaussian Splatting (3DGS) has become common, however deployment remains painful as the uncompressed file sizes can be massive. Current 3DGS compression systems combine multiple strategies for file size reduction, which can obscure where gains come from and limit component reuse across training pipelines. To make the gains more transparent, we propose KISS-GS, a modular compression pipeline named after the principle of keeping things simple, designed to decouple compression entirely from training.   Given a 3DGS scene reconstructed with vanilla 3DGS, we are able to reduce it through compaction by 15.7x using a combination of state-of-the-art pruning schemes. Then we encode it into an image-based format designed for simple, ubiquitous decoding. With the SOG-XT format, we propose a novel extension to Self-Organizing Gaussians with two main contributions: (i) Self-organizing 2D Codebooks and (ii) Parallel Representative Assignment Smoothing (PRAS), which leverages the symmetry of quaternion and scale parameterizations to produce 2D attribute grids more amenable to encoding.   This encoding reduces scene size by 6.6x. We show that optional encoding-aware fine-tuning yields a further 2.2x. Across standard 3DGS benchmarks, our simple and modular approach thus achieves a total of 85x to 319x reductions in the size of the scene over uncompressed vanilla 3DGS, setting new benchmarks for real-world scenes and surpassing tightly integrated methods in rate-distortion. Decoding relies solely on web-native image formats, and the modular design makes each stage easy to combine with future advances in reconstruction and compaction.   - 这种"训练-格式耦合"将压缩方案锁定在特定的训练流程上，当新的重建方法出现时，压缩方案无法直接复用或替换，阻碍了组件级的技术迭代。

- **整体含义**：KISS-GS证明：**复杂的编码器 + 简单的解码器**可以超越紧密集成的端到端压缩方法，同时使每个阶段的技术贡献可被清晰归因。

### 2. 论文提出的方法论：核心思想、关键技术细节

该论文提出一个四阶段模块化压缩管线，将压缩彻底与训练解耦：

#### 阶段一：3D重建（Reconstruction）
- 输入可以是任何标准3DGS `.ply` 文件，不依赖特定实现（INRIA、gsplat、Lichtfeld Studio等均可）。
- 使用标准3DGS参数化（均值、四元数协方差、球谐颜色、标量不透明度），不引入MLP、哈希网格或锚点结构，保持解码器简单。
- 主实验采用 gsplat MCMC 实现，30k迭代训练。

#### 阶段二：压缩精简（Compaction）—— POPSpa
- 这是论文提出的后训练剪枝方法，核心是将GaussianPOP的误差评分与GaussianSpa的"优化-稀疏化交替"方案结合。
- **有效秩正则化**（Effective Rank Regularization）：定义协方差矩阵的有效秩 `erank(Σ) = exp(−Σ pᵢ·log pᵢ)`，抑制针状高斯（erank≈1），鼓励盘状高斯（erank≈2），防止过拟合训练视角。
- **第一次剪枝**：使用GaussianPOP的每基元误差标准 `ΔSEₖ = ‖C_render − C′_render‖²`，移除得分最低的固定比例基元。
- **优化-稀疏化细化**：采用GaussianSpa的交替优化方案，在ℓ0稀疏约束下优化，后训练5k迭代，配合有效秩正则化。
- **第二次剪枝 + 微调**：重新计算误差，再去除冗余基元，额外5k迭代微调恢复质量。

#### 阶段三：编码（Encoding）—— SOG-XT格式
- 在Self-Organizing Gaussians (SOG)基础上扩展，使用PLAS并行分配算法将基元排列为2D网格，生成局部平滑的属性图，再通过WebP等标准图像编码器压缩。
- **两个核心新贡献**：
  - **(i) 自组织2D码本（Self-organizing 2D Codebooks）**：将高维球谐（SH）非DC系数用k-means聚类为码本，码本容量上限65,536（256×256）。码本质心再经PLAS排序，使码本自身在2D上局部平滑，并存储为UV索引图像（两个8bit通道）。
  - **(ii) 并行代表赋值平滑（PRAS）**：利用协方差分解的对称性——尺度排列（6种）、特征向量方向（4种）、四元数双覆盖（2种），合计48种等价参数化。PRAS在粗到细的模糊尺度上，为每个基元从其等价类中选择与平滑目标最一致的表示，消除人工方差，提升四元数和尺度网格的可压缩性。
- **具体编码方式**：
  - 均值：有符号对数重映射 + 16bit量化，拆分为高低两个字节平面，PLAS排序时高字节权重更大。
  - 球谐DC项：8bit图像直接存储；AC项：k-means码本 + UV索引。
  - 尺度：对数映射 + 8bit量化；不透明度：逆sigmoid映射 + 8bit量化。
  - 四元数：经PRAS优化后仅需99级量化（原始需255级）。
  - 额外存储活动掩码（active mask）以丢弃填充基元。

#### 阶段四（可选）：编码感知微调（Adaptation）
- 在SOG-XT编解码器"在环"的情况下微调4k步，使用直通估计器（straight-through estimator）处理取整操作。
- 固定编解码器的离散结构（活动掩码、PLAS顺序、SH分配及码本布局），仅更新连续参数和码本质心。
- 在微调过程中重新运行PRAS以维持协方差对称性优化。
- 输出格式与未微调的SOG-XT完全一致，解码器无需改变。

### 7. 优点

- **模块化设计**：明确分离重建、压缩、编码和适应四个阶段，每个阶段可独立评估、替换和消融，解决了"归因缺口"问题，推动3DGS压缩方法的组件级复用。
- **解码器极简**：仅需标准图像解码 + 轻量反量化操作，无需MLP/哈希网格/锚点等复杂结构，易于跨平台移植，适合浏览器和移动端部署。
- **技术新颖性**：
  - 自组织2D码本：对SH码本质心也进行PLAS排序，使码本自身具备空间局部性，带来无质量损失的"免费"压缩。
  - PRAS方法：巧妙利用协方差分解的48重对称性，在不改变所表示协方差的前提下提高属性图平滑度，实现更激进的量化。
- **后训练兼容性**：可接受任何标准3DGS `.ply` 输出，与具体训练实现解耦，天然兼容未来的重建算法改进。
- **评估严谨性**：仔细匹配计算预算（44k vs 40k），明确标注自报结果，遵循标准协议，消融实验系统完整。

### 8. 不足与局限

- **编码器复杂度**：论文自觉承认编码器（POPSpa、PRAS等）本身并不简单，与"KISS"原则存在一定张力。编码流程需要多个子模块协同，复杂性从解码端转移到了编码端。
- **Deep Blending数据集表现不佳**：在Deep Blending上无法达到INRIA质量参考点（有多个指标显示为负），HAC++反而表现更好。论文将其归因于标准splat重建在这类捕获场景下的局限，而非图像编码器的缺陷——但这也说明KISS-GS的性能上限受限于输入重建质量。
- **微调成本较高**：编码感知微调（4k步）比纯后训练编码贵约13倍（441s vs 34s），虽然可选，但若追求最佳压缩比需要相当的计算代价。
- **实验覆盖偏差**：
  - 部分对比方法（CodecGS、ContextGS、HEMGS等）使用自报数值，可能因评估协议差异而不可完全对比。
  - 论文没有评估对训练集视图的过拟合程度（虽然使用了留出验证集，但LPIPS指标上有多个方法未达到INRIA质量，可能反映了泛化问题）。
- **码本大小选择启发式**：SH码本大小设定为 `K ≈ N/8` 并限制在[64, 65536]，论文承认这是"保守默认值"，最佳大小依赖具体场景，研究者需手动调整。
- **缺少标准化格式规范**：虽然解码简单，但SOG-XT作为新格式，目前仅有参考Python实现，尚未成为像 `.spz` 或 `.sog` 那样的标准化开放格式（虽然与 `.sog` 有相似性）。
- **通用3DGS参数化局限**：不适用于锚点/MLP基的表示（如Scaffold-GS、HAC系列等），这些表示虽然压缩效果好但无法直接通过标准 `.ply` 文件传入本方法。
