## 摘要
神经辐射场（NeRF）和高斯溅射等3D场景表示技术在新型视图合成方面取得了显著进展，能够从任意视角生成高质量渲染。近来，这些技术已扩展到动态3D场景；然而，实现可持续的在线自由视点视频（FVV）流式传输仍然具有挑战性，尤其是在较长视频中，因为详细的场景表示需要巨大的存储需求，且对重建/渲染速度有很高的要求。为应对这些挑战，我们提出了量化锚定残差编码高斯流式传输（QuARC-GS），一种用于在线动态场景重建的感知量化的4D场景优化框架，在保持重建速度和质量的同时实现超高压缩。QuARC-GS使用单个规范帧和高度压缩的逐帧残差来表示场景。具体而言，我们通过两种互补策略压缩每个残差，针对运动、外观和致密化进行优化。我们引入了量化感知的锚定变形，在保持有意义变形的同时抑制不显著的运动更新，从而在低存储流式传输下维持重建质量。此外，我们设计了一种变化门控的致密化策略，仅在表现出真实时间变化的区域分配新高斯，有效消除冗余外观更新并减少存储开销。在广泛使用的数据集上进行的大量实验表明，与最先进方法相比，QuARC-GS在将每帧存储减少高达11倍的同时，实现了具有竞争力的重建质量和训练速度。

## Abstract
3D scene representation techniques such as neural radiance fields (NeRFs) and Gaussian splatting have made substantial progress in novel view synthesis, achieving high-quality renderings from arbitrary view angles. More recently, such techniques have been extended to dynamic 3D scenes; however, achieving sustainable online free-viewpoint video (FVV) streaming remains challenging, especially for longer videos, due to significant storage demands of detailed scene representations and high reconstruction/rendering speed needs. To address these challenges, we propose Quantized Anchored Residual Coding Gaussian Streaming (QuARC-GS), a quantization-aware 4D scene optimization framework for online dynamic scene reconstruction that achieves ultra-high compression while maintaining reconstruction speed and quality. QuARC-GS represents a scene using a single canonical frame and highly compressed per-frame residuals. Specifically, we compress each residual through two complementary strategies targeting motion, appearance, and densification. We introduce quantization-aware anchor deformation, which suppresses insignificant motion updates while preserving meaningful deformations, maintaining reconstruction quality under low-storage streaming. Furthermore, we design a change-gated densification strategy that allocates new Gaussians only in regions exhibiting genuine temporal changes, effectively eliminating redundant appearance updates and reducing storage overhead. Extensive experiments on widely used datasets demonstrate that QuARC-GS enables competitive reconstruction quality and training speed while cutting per-frame storage by up to 11$\times$ compared to the state-of-the-art.

## 二、论文提出的方法论

### 2.1 核心思想
- 以**单个规范帧（canonical frame）**的紧凑3DGS作为初始表示；
- 每帧仅优化和传输**残差信息**（锚点变形残差 + 新增高斯属性），而非完整场景；
- 通过**量化**使运动残差大量归零（映射为恒等变换），利用熵编码自然捕获稀疏性；
- 通过**变化门控**限制增量高斯的产生，避免静态区域被冗余重建。

### 2.2 关键技术细节

**（1）层次锚点变形（Hierarchical Anchor Deformation）**
- 采用3层锚点层级（L=3），第1层锚点数为 ⌈N/m⌉，后续每层锚点数约为上一层 1/3；
- 每个高斯通过1-NN搜索绑定到每层最近的锚点；
- 每个锚点存储变形参数 δa = (δt, δr) ∈ R⁷（3维平移 + 4维旋转四元数残差）；
- 高斯的新位置和旋转通过对所有层锚点变形求和获得；

**（2）量化感知锚定变形（Quantization-Aware Anchor Deformation）**
- 在前向传播中使用**直通估计器（STE）**对锚点残差进行取整量化：

$$\hat{\delta}_t = \Delta_t \left\lfloor \delta_t / \Delta_t \right\rceil, \quad \hat{\delta}_r = e + \Delta_r \left\lfloor (\delta_r - e)/\Delta_r \right\rceil$$

- 训练时使用量化值进行渲染，梯度通过全精度值回传，使锚点适应量化误差；
- 量化自然产生**动态/静态分割**：小于半量化步长的残差被映射为恒等变换，形成大量“静态锚点”；
- 量化后的整数值残差通过**经验香农熵**进行熵编码，静态锚点汇聚到零区间，显著降低编码成本，无需单独传输掩码。

**（3）变化门控致密化（Change-Gated Densification）**
- 在锚点变形应用后，计算连续帧之间光度损失差对高斯视图空间位置的梯度：

$$g_i = \left\| \nabla_{x_i} \left( L_1(\hat{I}, I_t) - L_1(\hat{I}, I_{t-1}) \right) \right\|_2$$

- 归一化权重 wᵢ = gᵢ / (gᵢ + median(g)) 调制累积致密化梯度；
- 只有变形无法解释的真实时间变化区域才会触发新高斯生成，静态高细节区域不产生冗余高斯。

**（4）零成本绑定（Zero-cost binding）**
- 锚点采样和1-NN绑定是规范几何与帧索引的确定性函数（基于伪随机种子），无需存储，绑定信息贡献**零字节**。

### 2.3 算法流程
1. **t=0**：使用噪声注入（系数0.01）的3DGS优化规范帧高斯集，约15,000迭代；
2. **t>0**：从上一帧热启动，执行约100次迭代的量化锚点变形优化 + 100次迭代的变化门控致密化；
3. 量化后的锚点残差与增量高斯属性经熵编码后传输；
4. 解码端使用传输量重建变形场景并渲染FVV。

## 六、论文的主要结论与发现

1. **压缩率显著提升**：QuARC-GS在N3DV上每帧存储仅 **36 KB**（含初始帧56 KB），在MeetRoom上仅 **18 KB**（含初始帧26 KB），较最紧凑的SOTA（ReCon-GS的400 KB）减少约 **11倍**；
2. **质量无损**：在N3DV上PSNR/SSIM/LPIPS与ReCon-GS完全持平（32.16 dB / 0.951 / 0.129），未因压缩而损失可感知质量；
3. **速度可接受**：训练速度（5.0秒/帧）接近最快在线方法，渲染速度（243 FPS）保持实时性；
4. **量化是低存储的关键**：无量化时存储激增至约 402 KB/帧（几乎等于ReCon-GS），量化使近静态锚点归零，大幅降低熵编码成本；
5. **变化门控抑制冗余增长**：无门控时每帧新增高斯数达468个且持续增长，启用后降至153个且场景规模近恒定；
6. **存在率失真最优步长**：量化步长存在“膝盖点”（knee point），过细增益极小、过粗导致质量下降并触发额外致密化。

## 七、优点（方法/实验设计亮点）

1. **视角新颖**：将量化感知训练引入锚点变形，直接在训练中优化最终传输的量化值，消除“训练/传输不匹配”问题；
2. **自然稀疏性**：量化使静态锚点自动归零，无需额外的掩码或门控信号，熵编码器自然地利用零区间的高概率质量，设计优雅；
3. **零成本绑定**：利用确定性种子函数消除绑定信息的传输，在表示层面实现“免费”压缩；
4. **互补性设计**：两个模块分别针对运动负载（量化锚点变形）和外观负载（变化门控致密化），问题切分清晰，具有明确的模块化与可解释性；
5. **实验指标全面**：不仅报告PSNR/SSIM/LPIPS，还同时覆盖存储（含/不含初始帧）、训练时间、渲染FPS、新增高斯数等多个维度，综合反映实际流式传输场景的需求；
6. **再现性处理**：对基线方法用官方代码在相同环境复现并多次平均，保证了对比公平性；同时开源代码（GitHub）。

## 八、不足与局限

### 实验覆盖方面
- **消融实验仅限N3DV**：量化与变化门控的有效性未在MeetRoom数据集上验证，泛化性证据稍显不足；
- **存储计算细节不透明**：论文以熵估计（经验香农熵）衡量编码成本，未展示实际熵编码器的真实码流大小，可能略微低估或高估实际存储；
- **无长视频实验**：虽然方法目标指向“长视频”流式传输，但两个数据集均为300帧，论文未展示在更长序列（如1000+帧）下的表现（如漂移、累积误差）。

### 方法本身局限
- **初始帧成本高**：需要高质量规范3DGS（15,000次迭代），首帧开销大，且每段新视频都需从头训练；
- **尚不具备实时性**：作者明确承认每帧约3–5秒的训练时间仍无法满足真正意义上的实时流式传输；
- **依赖多视角输入**：训练需要多路同步视频（N3DV 18–21路、MeetRoom 13路），对采集设备要求高，限制了实际应用场景；
- **自回归误差累积风险**：采用热启动的因果在线优化范式，错误或遗漏可能随时间累积，论文未对此误差传播进行深入分析。

### 偏差风险
- 锚点绑定依赖“确定性、种子化”的几何采样，若初始几何重建质量不佳，可能影响后续所有帧的绑定质量与残差编码效率；
- 变化门控阈值、量化步长（Δ_t=0.0017, Δ_r=0.01）等超参数需要针对场景尺度调优，论文未讨论超参数敏感性及通用默认值设置。
