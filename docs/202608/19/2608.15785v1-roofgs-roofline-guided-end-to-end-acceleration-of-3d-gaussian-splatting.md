## 摘要
3D高斯泼溅（3DGS）实现了实时新视角合成，但在高分辨率GPU上仍然受限。通过分阶段的Roofline特征分析，我们识别出两种不同的硬件瓶颈：全局内存流量主导前端，而指令吞吐量限制光栅化。在此分析的指导下，我们开发了RoofGS，一个应用瓶颈特定优化而非通用内核加速的渲染框架。对于内存受限的前端，我们设计了一种分辨率自适应的量化深度排序键，将每个键压缩为32位。对于计算受限的光栅化器，我们引入了一种范围感知的位级快速指数近似，专门针对不透明度剔除后的有界指数范围，并推导出每像素误差界。这两种核心技术辅以额外优化（内核融合、紧凑属性存储、剔除、双像素评估），进一步减少内存流量并提高指令级并行性。实验表明，在RTX 4090上以4K分辨率，RoofGS相对于3DGS实现了10.1倍端到端加速，吞吐量从61 FPS提升至616 FPS，而PSNR仅损失0.028 dB。

## Abstract
3D Gaussian Splatting (3DGS) enables real-time novel-view synthesis but remains limited on GPUs at high resolutions. Through a stage-wise Roofline characterization, we identify two distinct hardware bottlenecks: global memory traffic dominates the front end, whereas instruction throughput limits rasterization. Guided by this analysis, we develop RoofGS, a rendering framework that applies bottleneck-specific optimizations rather than generic kernel acceleration. For the memory-bound front end, we design a resolution-adaptive quantized depth sorting key that compresses each key to 32 bits. For the compute-bound rasterizer, we introduce a range-aware bit-level fast exponential approximation tailored to the bounded exponent range after opacity culling, with a derived per-pixel error bound. These two core techniques are complemented by additional optimizations (kernel fusion, compact attribute storage, culling, dual-pixel evaluation) that additionally reduce memory traffic and improve instruction-level parallelism. Experiments show that RoofGS achieves a 10.1$\times$ end-to-end speedup over 3DGS at 4K on an RTX 4090, increasing throughput from 61 to 616 FPS, with only a 0.028 dB PSNR loss.

## 1. 论文的核心问题与整体含义

- **研究动机**：3D Gaussian Splatting（3DGS）能够实现实时新视角合成，但在高分辨率（如4K）GPU 渲染时仍存在明显的性能瓶颈。虽然已有大量优化工作（如核级优化、管线级优化、表示级压缩），但这些方法普遍采用“局部/逐阶段”优化，往往在某个阶段取得收益后，瓶颈转移到其他阶段，导致端到端加速有限。
- **核心思想**：通过 **分阶段的 Roofline（屋顶线）性能建模**，识别出 3DGS 渲染管线中不同阶段的不同硬件瓶颈：
  - **前端（预处理、复制、深度排序）**：属于**内存带宽受限**阶段，全局内存流量是主要瓶颈；
  - **后端（光栅化/绘制）**：属于**计算受限**阶段，指令吞吐量是主要瓶颈。
- **整体意义**：提出了一种“瓶颈感知”的端到端优化框架 **RoofGS**，强调应该根据每阶段的硬件限制选择对应的优化手段，而不是对所有 kernel 做统一加速。最终在 RTX 4090 上实现约 10.1 倍端到端加速，PSNR 仅损失 0.028 dB，验证了该思路的有效性。

## 2. 论文提出的方法论

- 总原则：**内存受限阶段优先降低全局内存流量，计算受限阶段优先降低算术/指令开销**。具体包含三大块优化：

### 2.1 前端内存受限优化

- **紧凑属性存储（Compact Attribute Storage）**：
  - 球谐（SH）系数按 SH 阶数 \(d\) 和颜色通道 \(c\) 分别计算对称 INT8 量化缩放因子，避免单一全局尺度导致高频系数量化误差过大；
  - 旋转 \(r\)、尺度 \(s\)、不透明度 \(o\) 使用 FP16 存储，均值 \(\mu\) 保留 FP32 以确保投影精度；
  - 单个高斯属性占用从约 236 字节降至约 96 字节，内存流量减少约 59.3%。
- **分辨率自适应量化深度排序键（Resolution-Adaptive Sorting-Key Encoding）**：
  - 传统排序键为 64 位（32 位 tile ID + 32 位浮点深度），需要 8 趟 radix sort；
  - RoofGS 将排序键压缩为 **32 位**：高比特位存放 tile ID，低比特位存放量化深度；
  - 位数分配随分辨率动态调整：\(b_t = \lceil \log_2 N_t\rceil\) 用于 tile ID，剩余 \(32-b_t\) 位用于深度；
  - 深度先映射到预设的 \([z_{\mathrm{near}}, z_{\mathrm{far}}]\) 区间并量化，保证单调不减、不改变深度顺序；
  - 排序条目变小且排序趟数从 8 降到 4，显著减少排序内存流量。
- **预处理内核融合（Kernel Fusion）**：
  - 将投影、tile 复制、键值生成合并为一个 kernel；
  - 中间结果（\(\mu'\)、深度、逆协方差等）尽量保留在寄存器/共享内存中，避免多次全局内存读写；
  - 使用 shared-memory prefix sum 和每个线程块一次全局原子操作来分配复制条目；
  - 额外引入类似 SpeedySplat 的剔除策略，提前去除贡献极小的 Gaussians，降低复制因子和排序条目数。

### 2.2 后端计算受限优化

- **光栅化重组与双像素 ILP（Dual-Pixel Instruction-Level Parallelism）**：
  - 将高斯指数的二次型展开为像素相关项和高斯相关项分离的形式：
    \[
    a(x-u)^2 + b(x-u)(y-v) + c(y-v)^2
    = ax^2 + bxy + cy^2 - (2au+bv)x - (2cv+bu)y + C_0
    \]
  - 预先折叠系数 \(C_1 \sim C_6\)，将不透明度对数 \(\log o\) 也折叠进常数项，使内层循环中的指数计算退化为规则 FMA 序列；
  - 每个线程处理两个垂直相邻像素 \((x,y)\) 和 \((x,y+1)\)，共享同一份高斯属性；
  - 第二个像素的折叠指数通过增量公式更新：
    \[
    P(x,y+1) = P(x,y) + C_2x + C_3(2y+1) + C_5
    \]
    从而减少重复计算、提高指令级并行性和共享内存复用率。
- **范围感知快速指数近似（Range-Aware Fast Exponential）**：
  - 经过不透明度截断/剔除后，指数输入被限制在近似范围：
    \[
    P(x,y) \in [-\ln 255,\, 0] \approx [-5.541, 0]
    \]
  - 利用 Schraudolph 的单精度位级指数近似：
    \[
    I(P) = \left\lfloor P \cdot 2^{23}\log_2(e) + 2^{23}(127-\sigma) \right\rfloor,\quad
    \hat{\exp}(P) = \text{reinterpret\_float}(I(P))
    \]
    其中校准常数 \(\sigma = 0.045677\)；
  - 论文推导了相对误差上界 \(\varepsilon_{\max} \approx 0.03\)，并声称每像素颜色误差满足 \(|\Delta C|_\infty \le \varepsilon_{\max}\)，与混合高斯数量无关；
  - 该近似将昂贵的完整 IEEE 指数运算替换为整数/位级操作，降低 SFU 压力。

RoofGS 通过将常见的工程优化（属性压缩、排序键编码、内核融合、数学近简化）与硬件性能模型相结合，为 3DGS 渲染加速提供了一套清晰且实用的方法论。尽管在实验完整性和可复现性上尚有欠缺，但其“瓶颈感知”的优化思路和显著加速效果，使其成为该领域值得关注的工作。
