## 摘要
同时重建和理解3D环境对于具身智能体至关重要。为实现这一目标，馈送式语义3D高斯泼溅(3DGS)能从稀疏的多视角观测中高效构建语义场景表示。然而，现有方法缺乏显式的实例区分，主要支持基于类别或短语的语义查询。为此，我们提出GroupForward，一种实例分组的馈送式高斯泼溅模型，可从稀疏、无位姿且未标定的多视角图像中重建几何、外观、实例结构和语义。与现有方法将高维语义特征附加到每个高斯不同，GroupForward学习紧凑的实例嵌入，将高斯分组为跨视角一致的3D实例，将馈送式语义3DGS从逐高斯语义特征渲染重构为实例级语义聚合与传播。在这些实例分组的基础上，我们进一步提出一种可指涉场景推理框架(RSRF)，用于复杂的3D指涉分割。RSRF构建实例分组的3D场景图，并为给定的指涉表达式检索候选实例。然后，视觉语言模型在结构化实例证据和多视角观测上进行推理，以在候选中识别被指涉的实例。因此，RSRF将语言交互从简单的语义查询扩展到复杂的指涉场景推理。在语义重建和指涉推理上的实验证明了我们实例分组重建与推理框架的有效性。

## Abstract
Simultaneously reconstructing and understanding 3D environments is essential for embodied agents. Toward this goal, feed-forward semantic 3D Gaussian Splatting (3DGS) efficiently constructs semantic scene representations from sparse multi-view observations. However, existing methods lack explicit instance discrimination and mainly support category- or phrase-based semantic queries. To this end, we propose GroupForward, an instance-grouped feed-forward Gaussian splatting model that reconstructs geometry, appearance, instance structure, and semantics from sparse, unposed, and uncalibrated multi-view images. Unlike existing methods that attach high-dimensional semantic features to each Gaussian, GroupForward learns compact instance embeddings that group Gaussians into cross-view consistent 3D instances, reformulating feed-forward semantic 3DGS from per-Gaussian semantic feature rendering to instance-level semantic aggregation and propagation. Building on these instance groups, we further propose a Referential Scene Reasoning Framework (RSRF) for complex 3D referring segmentation. RSRF constructs an instance-grouped 3D scene graph and retrieves candidate instances for a given referring expression. A vision-language model then reasons over structured instance evidence and multi-view observations to identify the referred instance among the candidates. RSRF thereby extends language interaction from simple semantic querying to complex referential scene reasoning. Experiments on semantic reconstruction and referential reasoning demonstrate the effectiveness of our instance-grouped reconstruction and reasoning framework.

  1. **缺乏显式实例区分**：将高维语言对齐特征附加到每个高斯上，无法区分同类别中的多个实例，也难保持跨视图身份一致性；

## 2. 方法论（核心思想与技术细节）

### 2.1 核心思想

- 利用**持久化的3D实例组**作为桥梁，连接底层高斯重建与高层语言推理。
- 将“逐高斯高维语义特征渲染”转变为“**实例级语义聚合与传播**”：低维实例嵌入负责分组高斯，高维语义仅在实例级存储一次。

### 2.2 关键模块与技术细节

**（1）馈送式高斯泼溅 + 实例嵌入**
- 每个像素被提升为一个高斯原语，额外附加**紧凑实例嵌入** $e_{i,p} \in \mathbb{R}^{d_e}$，设 $d_e = 8$，远低于常用语义特征维度（如LSeg的512维）。
- 模型采用共享多视图编码器 + 几何解码器（相机头+深度头）+ 高斯解码器（属性头+实例头）的架构，基于VGGT初始化。

**（2）Gauge-Aligned Self-Rendering（规范对齐自渲染）**
- 除常规使用真值相机位姿的光度监督外，额外在**自预测位姿**下渲染重建场景，并计算对齐尺度：
  $$\gamma = \frac{\sum_{i\in C}\|t^c_i\|_2}{\sum_{i\in C}\|t^r_i\|_2}$$
  其中 $t^c_i$ 为上下文视图位姿，$t^r_i$ 为联合推理位姿；缩放后对上下文和目标视图同时进行光度监督，增强场景与预测相机位姿的一致性，同时保留真值位姿监督防止耦合畸变。

**（3）Rendering-Consistent Instance Learning（渲染一致的实例学习）**
- 直接目标：对上下文视图中的实例嵌入计算质心，使用 pull 损失拉近样本到质心、push 损失推开不同质心：
  $$L_{direct} = \lambda_{pull} L_{pull}^{direct} + \lambda_{push} L_{push}^{direct}$$
- 渲染目标：将高斯到实例的分配概率（基于嵌入到质心的距离软分配）作为可渲染属性，通过光栅化渲染到上下文和目标视图，与真值实例掩码计算 Dice 损失和 Focal 损失；同时渲染嵌入并进行 pull/push 约束：
  $$L_{render} = \lambda_{dice}L_{dice}^{render} + \lambda_{focal}L_{focal}^{render} + \lambda_{pull}L_{pull}^{render} + \lambda_{push}L_{push}^{render}$$
- 总实例学习损失：$L_{ins} = \lambda_{direct}L_{direct} + \lambda_{render}L_{render}$
- 推理时采用 HDBSCAN 聚类各视图嵌入，生成跨视图一致的3D实例组。

**（4）语义聚合与传播**
- 冻结的2D开放词汇模型（如LSeg）提取密集语义特征，按实例掩码池化得到每个实例的**语义原型**：
  $$f_k^{sem} = \frac{\sum_{v}\sum_u M_{v,k}(u)F_v(u)}{\sum_{v}\sum_u M_{v,k}(u)}$$
- 渲染实例分区，用分区权重与原型结合传播语义到目标视图。

**（5）Staged Curriculum Training（三阶段课程训练）**
- 阶段1：冻结实例头，训练重建（几何+外观）；
- 阶段2：冻结编码器/几何解码器/属性头，仅训练实例头；
- 阶段3：联合微调全模型，总损失 $L_{total} = L_{rec} + L_{ins}$。
- 无真值实例标签时，可用SAM2生成逐视图掩码，借助阶段1学到的几何和相机投影跨视图关联生成伪标签。

**（6）RSRF（可指涉场景推理框架）**
- 构建**实例分组3D场景图**：节点表示3D实例（含语义原型、3D位置/范围/体积、视图掩码、可见性），有向边编码空间关系（3D距离、相对高度、尺寸比、投影2D关系等）。
- **表达式引导的候选检索**：将指涉表达式解析为目标概念、基数、锚定实例、空间关系、视觉属性，按语义相关性、几何相关性和跨视图可见性评分，保留Top-K（K=8）候选。
- **VLM推理**：为每个候选构建节点中心证据包（全局概览、高亮掩码、目标裁剪、局部上下文等），使用 Qwen3-VL-8B-Instruct 在候选中选择目标实例，输出跨视图一致的3D分割掩码，无需额外生成新掩码。

## 6. 主要结论与发现

- GroupForward在**所有输入视图设置**下均优于现有方法，语义、几何和外观指标全面领先，验证了实例分组表示优于直接高维语义特征渲染。
- **零样本泛化**到Replica时仍保持最佳性能，表明实例级语义聚合有助于跨数据集泛化。
- **RSRF**在复杂指涉分割上大幅超越Uni3R（mIoU 0.6496 vs 0.2538），并优于Sa2VA（0.5012），同时提供跨视图一致的原生3D输出。
- 消融实验表明：
  - 渲染级实例监督对语义性能提升显著；
  - 实例嵌入表示比高维逐高斯特征带来更大的语义增益；
  - 自渲染主要改善外观质量；
  - 课程训练对稳定优化至关重要，缺失会导致严重性能下降；
  - 使用VGGT或SAM2伪标签时性能仅温和下降，证明方法可降低对真值标注的依赖。

## 7. 优点（亮点）

- **表示创新**：用8维低维实例嵌入替代高维语义特征，显式支持实例区分和跨视图一致性，计算更高效且语义在实例级传播，避免渲染退化。
- **任务拓展**：将前馈语义3DGS从“类别/短语查询”升级为“复杂指代推理”，通过3D场景图+VLM实现结构化语言交互，填补了重建与语言智能之间的空白。
- **无标签学习能力**：设计了伪标签流程（SAM2+VGGT），在无真值掩码/几何的情况下仍能取得有竞争力的性能，实用性强。
- **训练策略稳健**：三阶段课程训练有效防止早期优化崩溃，自渲染位姿对齐提升重建与相机一致性。
- **实验较全面**：涵盖单/多视图、跨数据集、多种任务、多个消融，并公开了训练资源消耗。

## 8. 不足与局限

- **实验范围局限**：主要评价集中在内室场景（ScanNet/Replica），未在室外或复杂开放场景中验证；指涉推理仅存在于一个数据集的测试，缺乏跨场景/跨语言多样性的验证。
- **RSRF消融不足**：未系统评估场景图构建、候选检索阈值、Top-K大小、VLM提示模板等因素对最终指涉分割的影响；VLM推理可能受候选检索错误传播影响。
- **对语义模型依赖**：最终语义质量依赖2D开放词汇模型（论文显示LSeg效果最佳，但CLIP较差），说明上层语义能力受限于底层特征模型。
- **计算成本**：虽比逐场景优化快，但单次训练仍需8×A100约30小时；推理时需额外运行HDBSCAN聚类和VLM，端到端延迟未报告。
- **伪标签依赖初始几何质量**：无标签场景中的SAM2跨视图关联依赖阶段1学到的几何，若初始重建误差大，伪标签质量会受限。
- **实例粒度问题**：实例数由聚类算法自动决定，可能无法精确匹配不同粒度（如“每个椅子”vs“整组沙发”）的指涉需求，文中未深入讨论。
