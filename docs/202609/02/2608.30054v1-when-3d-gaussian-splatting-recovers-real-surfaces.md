## 摘要
3D高斯溅射(3DGS)何时能恢复真实场景表面，而不仅仅是过度拟合与视图相关的表观？我们通过开发一个基于首次命中渲染抽象的数学框架来回答这个问题，该框架清晰地将几何与表观分离。我们证明了几何错位会通过视差有力地将空间纹理转换为高频角度信号。这建立了一个严格的可识别性窗口：如果角度容量有界，则表面一致的解在数学上更受青睐；如果无限制，则相同的图像可以由一个不正确的、不透明的广告牌几何完美解释。在合成压力测试上的实验证实了这一预测，表明广告牌失效恰好出现在高角度容量时。相反，在我们评估的标准捕获协议下的真实世界数据集中，即使在高球谐次数下，重建仍保持表面一致，这与丰富的空间纹理可以将广告牌解推到测试角度容量范围之外的预测一致。

## Abstract
When does 3D Gaussian Splatting (3DGS) recover the true scene surface rather than just overfitting view-dependent appearance? We answer this by developing a mathematical framework based on a first-hit rendering abstraction that cleanly isolates geometry from appearance. We prove that geometric misalignment forcefully converts spatial textures into high-frequency angular signals via parallax. This establishes a strict identifiability window: if angular capacity is bounded, surface-consistent solutions are mathematically preferred; if unrestricted, the same images can be perfectly explained by an incorrect, opaque billboard geometry. Experiments on synthetic stress tests confirm this prediction, showing billboard failures emerge precisely at high angular capacities. Conversely, in the real-world datasets we evaluate under standard capture protocols, reconstructions remain surface-consistent even at high SH degrees, which is consistent with the prediction that rich spatial texture can push billboard solutions outside the tested angular-capacity range.

### 一、核心问题与整体含义

论文围绕一个核心问题展开：**3D高斯溅射（3DGS）在何种条件下能够恢复真实场景的几何表面，而不仅仅是获得视觉上正确的渲染效果？**

- **技术背景**：3DGS已成为高保真实时渲染的主流工具，并被越来越多地作为几何重建的下游基础（如网格提取、物理仿真、接触建模）。但标准3DGS的训练目标只是图像重建损失，没有对表面恢复的显式约束，其"外观正确≠几何正确"的隐忧长期缺少理论视角的分析。
- **核心矛盾**：一个模型的渲染误差很低（PSNR很高）并不能保证其几何误差小（如nCD低）。随球谐阶数增高，模型可能在错误位置形成一张"不透明广告牌"（opaque billboard），仅靠视角相关颜色编码来生成正确像素，而几何完全偏离真实表面。
- **核心问题**：几何可辨识性——在什么条件下，优化景观更偏好真实表面而不是一个错误的错位代理表面？这一问题直接关系到将3DGS作为真实几何下游应用的可靠性。

### 二、提出的方法论

论文的核心贡献是建立一套理论分析框架：

1. **首次命中渲染抽象**：
   - 标准3DGS使用体渲染alpha混合，难以实现理论分析。论文提出首次命中模型，将渲染结果简化为射线经过的第一个不透明表面点的外观函数。
   - 解耦几何与外观：几何决定射线命中点，外观决定该点在不同视角下发出的颜色。预实验声称92.6%前景射线的合成质量集中在前三个高斯上，为该抽象提供经验依据。

2. **逐点投影最优性原理**：
   - 对于固定的候选表面U，所有射线损失可分解为每个表面点独立的最佳拟合问题。
   - 最优外观函数是"透射目标函数"在有限维球谐子空间 V_L 上的加权L²正交投影，最优损失等于该函数的投影残差能量。此原理将全局复杂优化转化为逐点信号处理问题。

3. **频率传输律（核心创新）**：
   - 真表面几何正确时，漫反射纹理落入SH degree-0子空间，不消耗任何角容量；仅需拟合具有Sobolev平滑性的高光残差，误差按 (1+L(L+1))^{-s_true} 快速衰减。
   - 当面几何错位时，视差效应将空间纹理变换为角度信号：若空间纹理频率为k、深度误差为Δz，则在错位表面诱导出角频率 **ω_fake ≈ kΔz**。模型需要以球谐表达这一高频角变化。

4. **可辨识窗口定理（Theorem 1）**：
   - 当 L < ω_fake 时，错位表面误差存在常数下界 c_0（无法用低阶球谐拟合该高频角信号）；真表面误差快速衰减至0。因此存在一个中间L窗口，其中**真表面严格更易拟合**。
   - 当 L ≥ ω_fake 时，理论证明（附录E）球谐有足够表达力让广告牌精确达到零训练损失，模型失去区分真假几何的能力。广告牌失效模式被严格数学证明。

5. **理论所需假设**：
   - 真实表面存在可见纹理正弦分量；
   - 错位表面存在不可忽略的深度间隙；
   - 高光残差不至于完全消除纹理（排除镜面、透明、强相机处理等极端场景）。

### 三、实验设计

1. **合成压力测试数据集**： 
   - 100个形状（25种基础几何×4种变体），用于在受控条件下验证理论预测。
   - 采用可调物体复杂度，仅在训练时改变SH次数L，从低阶（SH=3）到高阶（SH=24）进行系统扫描。

2. **真实基准数据集**（10个）：
   - DTU、MobileBrick、YCB-Video、T-LESS、ScanNet、ScanNet++、Matterport3D、HM3D、Tanks & Temples、ETH3D。
   - 涵盖物体级、室内场景、机器人操作场景等多种场景类型。

3. **评估指标**：
   - 几何质量：nCD（normalized symmetric Chamfer distance），由Gaussian中心点云与GT表面计算，通过Umeyama+ICP对齐、99百分位截断减少离散点干扰。
   - 外观质量：PSNR。

4. **分类标准**： 
   - Opaque billboard：PSNR ≥ PSNR_best - 2dB 且 nCD ≥ 5×nCD_best；
   - Billboard onset：2×nCD_best < nCD < 5×nCD_best；
   - Surface-consistent：nCD ≤ 2×nCD_best。

5. **对比方法**：没有对比其他3D重建方法，唯一的独立变量是球谐最高次数L（同一框架下自对比）。实验意图是对理论预测进行验证与证伪检验。

### 六、主要结论与发现

1. **理论层面的核心结论**：
   - 3DGS的几何可辨识性受限于角容量与空间纹理频率的关系；
   - 过大的SH容量允许错位billboard用高频角度信号拟合空间纹理；
   - 存在一个"中间L可辨识窗口"：即L不能太小（否则无法拟合高光残差）也不能过大（否则会失去辨别能力）；
   - 高空间纹理复杂度（k大）使得ω_fake超出常用SH范围，从而真实数据在实践上进入"安全区间"。

2. **合成实验中验证理论预测**：大角容量确实可迫使广告牌失效发生，且渲染质量保持高水准（PSNR差距在2dB内）。

3. **真实实验表明**：在标准多视角采集协议和SH≤24的配置下，未观察到不透明广告牌失效；高空间纹理的"保护效应"是真实场景中几何保持稳定的主要原因。

4. **方法论警惕意义**：3DGS作为几何输出的可靠性不是自动成立的性质，需要受控的角容量配合场景纹理特征共同保证。

### 八、不足与局限

- **首次命中抽象的简化和适用边界**：预实验仅统计92.6%前景射线的alpha集中度，用的场景是"大体不透明"的受控类型；半透明植被、毛发或体积效果场景中，此抽象可能失效，理论预测未必适用。
- **理论假设较强**：需要纹理正弦、深度间隙、残差幅度上界等条件，对真实世界复杂BDRF和光照模型局限性明显；排除镜面、折射、曝光变化等情形限制了理论的适用范围。
- **对图像重建目标的固守**：只分析纯光度损失的属性，未考虑法向/深度正则化、几何感知高斯类方法等改进的作用；正文虽明确"不应直接外推至几何正则化方法"，但仍可看作是模型类型的边界。
- **真实实验覆盖有限**：仅报告每个数据集SH=2个端点的训练，未做全谱SH扫描；真实场景中未见广告牌失效，但缺乏进一步压力测试（增大L到极限或将深度间隔系统性放大等）；没有多随机种子误差棒，统计可靠性存疑。
- **几何评价与数据统计**：依靠Gaussian中心点云而非表面重建来评估，可能受稀疏离群点影响；nCD与真值网格对齐依赖点云IO等过程，会引入新的不确定性。
- **算力与实现细节缺失**：未报告GPU类型、训练时长等，数据集的训练协议（视图数量、分辨率等）也未完整交代，降低可复现性。
- **文化局限与验证缺口**：理论给出存在性结论和近似窗口，但缺少对实际3DGS优化过程中梯度动态的跟踪验证；"L超过ω_fake导致广告牌可行"是否意味着会被优化器实际找到，其与"工程崩溃边界"的关系尚不透明。
