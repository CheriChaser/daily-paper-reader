## 摘要
我们提出了EdMCGS（事件驱动马尔可夫链高斯泼溅），一种端到端方法，用于从极低帧率RGB和事件流重建动态3D场景，并可在任意中间时间戳进行渲染。仅依赖RGB图像的方法由于缺乏连续帧之间的证据而产生大量伪影。为了补充缺失的证据，我们将场景运动建模为事件驱动的马尔可夫链，其中稀疏的RGB帧在其各自时间戳锚定状态，而间隔内记录的事件驱动跨间隔的状态转移。由于转移过程读取当前间隔的事件，在推理时保持活跃，并直接从事件而非通过插值生成3D高斯体的中间运动，这使我们的方法与先前仅将事件用作训练时监督的工作不同。状态由一组紧凑的控制点承载，每个控制点由其自身图像投影邻域内采样的事件驱动，并且时间局部等距项保持传播运动局部刚性。在合成和真实世界场景上的实验表明，EdMCGS在实时渲染的同时，优于基于RGB和基于事件的基线，并且使用的3D高斯体数量远少于最强的事件基线。我们在https://github.com/joseclipse/EdMCGS发布了源代码和一个新数据集。

## Abstract
We present EdMCGS (Event-driven Markov chain Gaussian Splatting), an end-to-end method for reconstructing dynamic 3D scenes from extreme-low-frame-rate RGB together with an event stream, which can then be rendered at any intermediate timestamp. Methods relying solely on RGB images generate numerous artifacts due to the lack of evidence from between consecutive frames. To supply this missing evidence, we model the scene motion as an event-driven Markov chain, in which the sparse RGB frames anchor the state at their own timestamps while the events recorded within an interval drive the transition across it. Since the transition reads the events of the current interval, it remains active at inference and produces the in-between motion of the 3D Gaussians directly from the events rather than by interpolation, which sets our method apart from prior work that uses events only as training-time supervision. The state is carried by a compact set of control points, each driven by the events sampled in the neighborhood of its own image projection, and a temporal local isometry term keeps the propagated motion locally rigid. Experiments on synthetic and real-world scenes show that EdMCGS outperforms both RGB-based and event-based baselines, while rendering in real time with far fewer Gaussians than the strongest event-based baseline. We release our source code and a new dataset at https://github.com/joseclipse/EdMCGS.

## 1. 核心问题与研究动机

- **问题背景**：动态三维场景重建与自由视角合成在自动驾驶、具身智能和虚拟现实等领域有广泛应用。现有基于 NeRF 和 3DGS 的动态重建方法均依赖**密集采样的 RGB 输入**，以支撑帧间的运动插值。
- **核心挑战——极低帧率（Extreme-Low-Frame-Rate）**：在带宽受限、长曝光、存储压力等实际场景下，可用 RGB 帧率极低（如 5–10 fps）。此时，帧间存在较大的时间空洞，仅靠 RGB 训练的方法缺乏帧间证据，容易对少量离散时间戳过拟合，在渲染未观察的中间时刻时产生撕裂、鬼影等严重伪影。
- **事件相机的引入**：事件相机以微秒级时间分辨率异步输出逐像素亮度变化，天然密集覆盖 RGB 缺失的时间区间，能补充帧间动态信息，是解决上述问题的有力线索。
- **现有工作的不足**：
  - 已有事件+动态重建方法（如 DEGS、E-D3DGS、Ev4DGS 等）仅将事件作为**训练阶段的监督信号**，推理时仍需依赖时间插值，没有在推理中真正"读取"事件。
  - 大多管线笨重：依赖预训练光流网络、动态-静态分离掩码、多视角事件相机阵列等。
  - 多数方法未开源代码与数据，缺乏可复现的对比基线。
- **论文定位于回答**：动态场景的帧间运动能否在推理时**直接由事件证据驱动**生成，而非依赖插值？

## 2. 方法：EdMCGS

### 2.1 核心思想：事件驱动的马尔可夫链

- 将动态场景运动建模为**事件驱动的马尔可夫链**：
  - **状态**：控制点集合的构型 `S_t = {μ_j^t}`；
  - **锚定帧**：稀疏 RGB 帧在各自时间戳 τ₁<τ₂<…<τ_N 锚定状态；
  - **转移算子**：`S_t = T(S_{τ(t)}, E[τ(t), t])`，即由当前锚定状态与区间内累积的事件共同决定当前时刻的状态，且转移仅依赖当前区间，具有马尔可夫性；
  - 由于转移过程**读取当前区间内的事件**，因此推理时仍然保持活跃，可以直接从事件生成中间运动，而非靠插值。
- 相较先前事件工作（事件只做训练监督）的关键区别——**在推理时事件依然参与运动生成**。

### 2.2 技术流程

1. **控制点+线性混合蒙皮（LBS）**：
   - 从规范空间高斯集合中通过最远点采样选出 M 个控制点；
   - 每个高斯绑定 K 个最近控制点，控制点运动通过 LBS 驱动高斯形变（借鉴 SC-GS 的低秩运动表达）。
2. **双分支位移**：
   - **RGB 先验分支**：MLP 以时间编码和位置编码输出控制点的基线位移 δμ^{f,t}（只对 M 个控制点计算，保持低维）；
   - **事件驱动分支**：`δμ_j^t = δμ_j^{f,t} + g_φ(γ(μ_j), m_j^t)`，其中 m_j^t 是局部位移代码；
   - 事件分支最后一层零初始化并逐步加热，确保先建立 RGB 锚定场再引入事件修正。
3. **局部事件采样（Local Event Sampling）**：
   - 将区间 [τ(t), t] 内的事件按极性累积为 2D 事件图；
   - 轻量 CNN Φ 编码事件图为保持空间布局的特征图；
   - 将每个控制点投影到事件相机平面，用**双线性采样**读取其自身投影位置的局部位移代码 m_j^t；
   - 这样，运动部件触发的事件只驱动覆盖该部件的控制点，避免与全局背景/噪声混杂的问题。
4. **时间局部等距正则化（TLI）**：
   - 在控制点的 KNN 图上，约束相邻控制点在邻近两个变形时刻 t₁、t₂ 间的边长变化，即 `L_TLI = Σ_{(j,k)∈E} (ℓ_jk(t₁) − ℓ_jk(t₂))²`；
   - 与 SC-GS 的 ARAP 不同：TLI 无需旋转估计、不比较变形与规范构型，而是比较**两个变形时刻之间的边长一致性**，从而使传播的运动保持局部刚性。
5. **训练目标**：
   - 光度损失：ℓ₁ + D-SSIM；
   - 事件损失：基于事件生成模型（EGM），将两帧渲染图的 log-luminance 差与累积事件对比，并 detach 颜色梯度，使事件只约束几何与运动、不污染颜色；
   - 正则项：TLI + KNN 拉普拉斯平滑项；
   - 总损失:加权求和。

## 6. 主要结论与发现

- EdMCGS 全面优于 RGB 基线和现有事件基线，在所有帧率与指标上排名第一：
  - 合成数据集：10 fps 达 31.56 dB PSNR，5 fps 达 29.37 dB；
  - 真实数据集：31.13 dB PSNR，同样最优。
- **帧率越低，优势越大**：事件证据在空洞区间内不变，因而不依赖时间插值的方法随帧率降低退化更缓慢。
- **E-D3DGS 的局限被验证**：其依赖静态-动态分解/静态背景锚定，当前景运动占画面主导（如 Jumpingjack 序列）时性能显著崩塌；EdMCGS 无需掩码或分解，所有场景均最优。
- **效率优势**：相较最强基线 E-D3DGS，EdMCGS 训练更快、渲染更快、高斯体数量少数倍（合成仅约 1/6），说明事件证据更适合由轻量运动模型读取，而非在重型场景表达中吸收。

## 7. 方法亮点与优点

- **范式创新**：首次将事件从"训练监督"提升为"推理时活跃的运动驱动器"，实现了中间运动直接从事件证据产生，而非时间插值——这是论文最核心的方法论贡献。
- **局部性设计**：控制点在其图像投影位置双线性采样局部位移代码，空间上与事件来源对齐，避免了全局池化造成的物体/背景事件混淆。设计简单且无需显式半径或掩码。
- **轻量高效**：不需要预训练光流模型、外部姿态网络或运动掩码；端到端、免掩码、无外部依赖。
- **正则化设计有意义**：TLI 不比较变形与静态规范态，而是比较两个近邻变形时刻之间的边长关系，无旋转估计开销，直接稳定帧间运动的时空一致性。
- **实验设计较严谨**：
  - 统一 LPIPS 骨干确保公平；
  - 内部基线 "w/o Markov" 准确对应了先前的"事件只做监督"范式，有效隔离了事件驱动转移的贡献；
  - 逐场景结果完整公开，便于判断方法适用边界。
- **可复现性**：开源代码与合成数据，为社区提供可复现的基准。

## 8. 不足与局限性

- **相机姿态假设**：方法假定相机姿态已知，与多数可变形高斯基线一致；虽然 DEGS 通过附加姿态网络解决，但在极端低帧率+事件场景下姿态联合优化仍是开放问题。
- **合成数据贴近模拟**：真实感有限，事件模拟基于 ESIM 理想模型，现实中对比度阈值、噪声、偏置等各像素不一致，对方法在真实事件相机上的鲁棒性有待更充分的评测。
- **真实数据集中运动的动态前景较小**：从逐场景结果看，真实场景大部分区域为静态背景，一定程度上稀释了帧间运动重建难度的考验；动态物体占比很高、运动幅度大的真实场景验证不足。
- **对比不直接**：由于多个最新事件基线（DEGS、Ev4DGS、E-4DGS）未开源，无法进行正面竞争，令最强可复现基线实验不完整。
- **高斯数量/训练成本仍有进一步降低空间**：虽然实验显示高斯数远少于 E-D3DGS，但相对 D-3DGS 仍多约 1000 个；更好的压缩策略有待探索。
- **方法本身不隐含动态/静态先验**：全部由数据驱动，当场景事件密度极低时，事件分支能否提供可靠位移需进一步验证。
