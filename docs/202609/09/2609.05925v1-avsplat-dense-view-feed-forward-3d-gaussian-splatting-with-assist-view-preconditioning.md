## 摘要
无位姿前馈3D高斯泼溅能够从未标定的多视图图像进行新视角合成。尽管更多视图理应提升性能，但现有方法在稠密视图输入下常常退化，因为全局注意力会将注意力分散到大量标记上，而朴素的体素融合会将许多高斯平均成过度平滑的表示。我们提出AVSplat，一个将额外视图转化为聚合和表示可靠信号的框架。在全局注意力之前，每个视图与一组根据相关性和多样性选择的辅助视图进行单次轻量交互，缓存的特征提供了聚焦的场景上下文，从而稳定对应关系。在表示方面，我们使用自适应温度感知的体素融合，在高占用率下根据占用率和点置信度引导来锐化归属。关键是，AVSplat恢复了正向视图缩放，即随着输入视图增加，性能保持稳定或提升，而不是在稠密视图区域退化。消融实验表明，辅助视图预条件主要防止稠密视图退化，而占用率引导的体素融合贡献了大部分单点图像质量提升。

## Abstract
Pose-free feed-forward 3D Gaussian Splatting enables novel view synthesis from uncalibrated multi-view images. Although more views should improve performance, existing methods often degrade with dense-view inputs because global aggregation spreads attention over many tokens, and naive voxel fusion averages many Gaussians into overly smooth representations. We present AVSplat, a framework that turns additional views into reliable signals for both aggregation and representation. Before global attention, each view performs a single lightweight interaction with a small set of Assist Views chosen for relevance and diversity, and the cached features provide a focused scene context that stabilizes correspondence. For representation, we use adaptive temperature-aware voxel fusion that sharpens attribution under high occupancy, guided by occupancy and point confidence. Crucially, AVSplat restores positive view scaling where performance remains stable or improves as more input views are added, instead of degrading in the dense-view regime. Ablations show that Assist View Preconditioning is primarily responsible for preventing dense-view degradation, while Occupancy-guided Voxel Fusion contributes most of the single-point image-quality gains.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**

- 前馈式 3D 高斯泼溅（Feed-forward 3DGS）方法能够在一次前向传播中，从无位姿标定的多视图图像直接预测相机参数和 3D 高斯基元，实现新视角合成。其核心优势在于无需逐场景优化，依赖几何基础模型（如 DUSt3R、VGGT）直接从图像推断三维结构。
- 一个直观且重要的预期是：**输入视野越多，重建质量应当越好**。然而，论文指出了现有方法在稠密视图（如 32、48、64 甚至更多视图）下的"反直觉退化"现象——输入视图增多反而导致重建保真度下降。
- 论文识别出导致该退化的**两大结构性原因**：
  1. **全局注意力分散**：在无位姿条件下，全局聚合依赖 softmax 注意力在大量 token 间发现对应关系。当序列（视图）增长时，注意力质量在多候选间被稀释，正确匹配的权重被削弱，导致跨视图一致性下降。
  2. **朴素体素融合过度平滑**：逐像素高斯在体素化后，落入同一体素的大量高斯被简单的归一化平均。强贡献者被弱势者稀释，等效于低通滤波器，损失高频细节；当置信度差异大而融合权重不自适应时问题更严重。
- 论文提出的核心意义在于：将"额外视图"从负担转化为可靠信号，从而在稠密视图输入下恢复**正向视图缩放（Positive View Scaling）**，即更多输入持续带来性能改善而非退化。

## 2. 论文提出的方法论

**核心思想与整体架构：**

AVSplat 构建于 VGGT 风格的 Transformer 多视图几何编码器之上，整体管线包括：图像编码 → 辅助视图预条件（AVP）→ 全局聚合 → 解码（相机参数、深度、高斯参数）→ 体素化 → 占用引导体素融合（OVF）→ 可微光栅化渲染。其两大核心创新模块如下：

### 模块一：辅助视图预条件（Assist-View Preconditioning, AVP）

**目标**：在全局注意力之前，让每个视图先从少量精选辅助视图中获取聚焦的场景上下文，缓解稠密视图下的注意力稀释与跨视图匹配不稳定。

**关键步骤与公式逻辑：**

1. **视图描述子提取**：对视图 $s$ 的 P 个 patch tokens 做平均池化得到描述子 $z_s \in \mathbb{R}^d$。
2. **候选池构建**：基于余弦相似度 $m_{st}$ 选取 Top-M 近邻构成候选池 $N(s)$。
3. **覆盖驱动的辅助视图选择**：通过贪心算法（近似子模优化）选取 K 个多样性好、相关性强、可靠性高的辅助视图。目标函数包含三项——token 级覆盖增益（当前视图 token 被辅助视图匹配支持的程度）、视图可靠性（token 方差推导）、视图间冗余惩罚。贪心过程在分离（detached）的 token 上执行，视为不可微的旁路计算。
4. **轻量条件化交互**：对当前视图做一次单头/多头交叉注意力（query 来自当前视图，key/value 来自辅助视图拼接），得到上下文特征。
5. **门控残差融合**：$X^{out}_s = X_s + \gamma(g)\tilde{X}_s$，其中门控系数 $\gamma(g)$ 随训练步数从近 0 线性增至 1，并在训练早期对辅助分支停止梯度传播以稳定优化。
6. 稀疏视图（如 3 或 6 视角）下因可用视图太少，AVP 被禁用。

**实现细节**：K=4，warm-up 2000 步，ramp 8000 步，前 1500 步停止梯度。

### 模块二：占用引导的体素融合（Occupancy-guided Voxel Fusion, OVF）

**目标**：替代均匀温度/权重的朴素体素融合，使体素内融合权重随占用密度和局部几何一致性自适应。

**关键步骤与公式逻辑：**

1. 对体素 $v$，定义候选高斯集合 $G_v$ 与占用数 $n_v = |I_v|$。
2. **自适应温度公式**：
$$\tau_v = \text{clip}\left(\tau_{\min},\; \tau_0 \left(\frac{n_v}{n_{\text{ref}}}\right)^{-\alpha} \psi_v,\; \tau_{\max}\right)$$
其中 $\tau_0$ 为基础温度、$n_{\text{ref}}$ 为参考占用数、$\alpha$ 为占用指数。
3. **几何一致性因子**：$\psi_v = \frac{1}{1+\lambda\sigma_v^2}$，其中 $\sigma_v^2$ 为体素内 3D 点的空间方差。点越一致，该体素越"可靠"，温度越低、权重越锐利。
4. **融合权重**：以 $c_i/\tau_v$ 为 logits 做 softmax 得到各候选权重 $w_i$；高占用 → 低温 → 权重分布锐化，高置信度高一致性的贡献者主导；低占用 → 高温 → 分布平滑、保持信息包容性。
5. **截断机制**：对权重降序排序，保留累计质量达阈值（0.8）的最短前缀后再归一化，抑制离群值影响。
6. 整个过程可微、端到端联合训练。

**实现细节**：基础温度 0.7，占用指数 0.5，参考计数 8，温度裁剪 [0.15, 2.0]，几何方差权重 2.0，top-mass 阈值 0.8。

## 6. 论文的主要结论与发现

1. **AVSplat 恢复了稠密视图下的正向缩放**：在 DL3DV 上，输入视图从 32 增至 64 时，AVSplat PSNR 从 21.54 持续提升至 21.67 dB，而 AnySplat 在约 21.05-21.14 dB 区间饱和/停滞。
2. **在 ACID 高重叠压力测试中优势显著**：从 48 到 72 视图，AnySplat 从 23.12 dB 降至 22.45 dB（退化 0.67 dB），AVSplat 从 23.15 升至 23.24 dB，形成 0.79 dB 的净优势。
3. **注意力诊断证实了 AVP 的结构性作用**：AVSplat 将交叉注意力归一化熵从 0.693 降至 0.642，GeoMass@1patch（单 patch 宽度极线带内注意力质量）从 0.286 提升到 0.374（绝对 +8.8 点，相对 +30.8%），注意力集中在几何合理区域约从随机基线的 2.9× 增至 3.7×。
4. **消融归属清晰**：占用引导体素融合贡献了单点图像质量的主要提升（64 视图下 PSNR +0.43），而辅助视图预条件主要防止稠密视图退化，在长序列下稳定全局匹配。

## 7. 优点

- **问题选择精准且实用**：正确定位了稠密视图输入下被普遍忽略的退化问题，并指出两个深层的结构性原因，具有较高的实际价值（多视图重建应用中往往需要大量视图输入）。
- **方法设计轻量而优雅**：辅助视图选取只需一次轻量交互的"预条件"步骤，不增加全局注意力本身的计算负担，避免了对高成本稠密全局注意力内核的复杂改动；KV 缓存和分层 token 采样提升了效率。
- **模块可解释性强**：AVP 的设计目标可直接通过注意力熵和 GeoMass 等诊断指标进行验证；OVF 的温度自适应机制具有清晰的物理和几何直觉（占用高则锐化，占据低则包容），消融归属明确。
- **恢复正向视图缩放是可量化、可检验的核心优势**，比单纯提高几个百分点的 PSNR 更具系统性价值。
- 论文对输入的相机位姿不作要求（真正无位姿），且与现有 3DGS 渲染管线兼容。

## 8. 不足与局限

- **基线覆盖不充分**：稠密视图下仅有 AnySplat 一个可运行基线，缺乏对 ZPressor（可扩展至 100+ 视图）、MuSASplat 等最新方法的对比。NoPoSplat 和 FLARE 的 OOM 说明方法本身的高显存门槛，但也间接规避了与更高效方法的对比。
- **稀疏视图表现存在短板**：AVP 在稀疏视图下被禁用，导致 AVSplat 在部分稀疏设置（如 DL3DV 3 视图，DL3DV 3 视图 PSNR 低于基线 0.63 dB）弱于 AnySplat，说明方法并未同时改善稀疏视图性能。

- **资源信息不完整**：未报告训练总时长、GPU 总数量、端到端推理时间或显存占用增长曲线，难以准确判断相对计算成本/收益比。
